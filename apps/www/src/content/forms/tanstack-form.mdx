## Anatomy

Render each `Field` inside a `form.Field` and pass the field state to it.

```tsx {3-4,6,13}
<form.Field name="username">
	{(field) => {
		const isInvalid = field.state.meta.isTouched && !field.state.meta.isValid
		const errorMessage = field.state.meta.errors[0]?.message
		return (
			<Field name={field.name} invalid={isInvalid}>
				<FieldLabel>Username</FieldLabel>
				<Input
					value={field.state.value}
					onChange={(e) => field.handleChange(e.target.value)}
					onBlur={field.handleBlur}
				/>
				{isInvalid && <FieldError match>{errorMessage}</FieldError>}
			</Field>
		)
	}}
</form.Field>
```

- `form.Field` connects the control to TanStack Form.
- `invalid` on `Field` is true once the field is touched and not valid.
- `match` on `FieldError` shows the message from TanStack Form.

## Form

### Create a Schema

Define the form values with Zod, or any Standard Schema library.

```tsx title="form.tsx"
import { z } from "zod"

const schema = z.object({
	name: z.string().min(1, "Name is required."),
	message: z
		.string()
		.min(10, "Message must be at least 10 characters.")
		.max(200, "Message must be 200 characters or less."),
})
```

### Set Up the Form

Pass the schema to `onDynamic` in `validators` and set `validationLogic: revalidateLogic()`. The form then validates on submit, and on every change after that.

```tsx {6-18,22-25} title="form.tsx"
import { revalidateLogic, useForm } from "@tanstack/react-form"

// ...

export default function ExampleForm() {
	const form = useForm({
		defaultValues: {
			name: "",
			message: "",
		},
		validationLogic: revalidateLogic(),
		validators: {
			onDynamic: schema,
		},
		onSubmit: async ({ value }) => {
			console.log(value)
		},
	})

	return (
		<form
			onSubmit={(e) => {
				e.preventDefault()
				form.handleSubmit()
			}}
		>
			{/* ... */}
		</form>
	)
}
```

Then add a `form.Field` with a `Field` for each value. The demo at the top of this page has the full code.

## Submitting

### Pending State

To show progress while the form submits, read `isSubmitting` from the form store and pass it to `loading` on the submit button.

```tsx {3,11}
import { useStore } from "@tanstack/react-form"

const isSubmitting = useStore(form.store, (state) => state.isSubmitting)

<form
	onSubmit={(e) => {
		e.preventDefault()
		form.handleSubmit()
	}}
>
	<Button type="submit" loading={isSubmitting}>
		Send
	</Button>
</form>
```

### Focus the First Invalid Field

To move focus to the first invalid field when a submit fails, focus it in `onSubmitInvalid`.

```tsx {1,5-11,15}
const formRef = useRef<HTMLFormElement>(null)

const form = useForm({
	// ...
	onSubmitInvalid: () => {
		formRef.current
			?.querySelector<HTMLElement>(
				':is(input, textarea, button, [tabindex])[aria-invalid="true"]',
			)
			?.focus()
	},
})

<form
	ref={formRef}
	onSubmit={(e) => {
		e.preventDefault()
		form.handleSubmit()
	}}
>
	{/* ... */}
</form>
```

## Validation

### Field Validators

To validate a single field, set `validators` on `form.Field`.

```tsx {3-5}
<form.Field
	name="username"
	validators={{
		onDynamic: z.string().min(3, "Username must be at least 3 characters."),
	}}
>
	{(field) => (/* ... */)}
</form.Field>
```

### Validation Modes

To choose when validation runs, set `mode` and `modeAfterSubmission` on `revalidateLogic`.

```tsx {2-5}
const form = useForm({
	validationLogic: revalidateLogic({
		mode: "blur",
		modeAfterSubmission: "change",
	}),
	validators: {
		onDynamic: schema,
	},
})
```

| Option | Values | Description |
| --- | --- | --- |
| `mode` | `"submit"`, `"blur"`, `"change"` | When to validate before the first submit. Default `"submit"`. |
| `modeAfterSubmission` | `"change"`, `"blur"`, `"submit"` | When to validate after the first submit. Default `"change"`. |

## Server-Side Errors

To show an error returned by the server, set it with `formApi.setFieldMeta`. Submit the form to see one.

<ComponentPreview name="form-tanstack-form-server-errors-demo" />

```tsx {8-17}
const form = useForm({
	defaultValues: { username: "" },
	validationLogic: revalidateLogic(),
	validators: { onDynamic: schema },
	onSubmit: async ({ value, formApi }) => {
		const res = await createUser(value)

		if (!res.success) {
			formApi.setFieldMeta("username", (prev) => ({
				...prev,
				errorMap: {
					...prev.errorMap,
					onDynamic: { message: res.message },
				},
			}))
			return
		}
	},
})
```

### Date Picker

Pass `field.state.value` to `selected` and `field.handleChange` to `onSelect` on `Calendar`, and set `aria-invalid` on the trigger. Use `null as Date | null` as the empty value in `defaultValues`. Give `FieldError` an `id` and pass it to `aria-describedby` on the trigger so the error is announced.

<ComponentPreview name="form-tanstack-form-date-picker-demo" />

```tsx {9,16-18}
const id = useId()
const errorId = useId()
const [open, setOpen] = useState(false)

<Field name={field.name} invalid={isInvalid}>
	<FieldLabel htmlFor={id}>Start date</FieldLabel>
	<Popover open={open} onOpenChange={setOpen}>
		<PopoverTrigger
			render={<Button id={id} variant="outline" aria-describedby={errorId} aria-invalid={isInvalid || undefined} onBlur={field.handleBlur} />}
		>
			{field.state.value ? format(field.state.value, "MMM d, yyyy") : "Select a date"}
		</PopoverTrigger>
		<PopoverPopup className="w-auto p-0" align="start">
			<Calendar
				mode="single"
				selected={field.state.value ?? undefined}
				onSelect={(next) => {
					field.handleChange(next ?? null)
					setOpen(false)
				}}
			/>
		</PopoverPopup>
	</Popover>
	{isInvalid && <FieldError id={errorId} match>{errorMessage}</FieldError>}
</Field>
```

## Array Fields

To let people add and remove fields, set `mode="array"` on `form.Field`. Render a `form.Field` for each item, and call `pushValue` and `removeValue` to change the list.

<ComponentPreview name="form-tanstack-form-array-demo" />

```tsx {1,4-5,23,37}
<form.Field name="emails" mode="array">
	{(arrayField) => (
		<>
			{arrayField.state.value.map((_, index) => (
				<form.Field key={index} name={`emails[${index}].address`}>
					{(field) => {
						const isInvalid = field.state.meta.isTouched && !field.state.meta.isValid
						const errorMessage = field.state.meta.errors[0]?.message
						return (
							<Field name={field.name} invalid={isInvalid}>
								<div className="flex gap-2">
									<Input
										value={field.state.value}
										onChange={(e) => field.handleChange(e.target.value)}
										onBlur={field.handleBlur}
										aria-label={`Email ${index + 1}`}
									/>
									<Button
										type="button"
										variant="ghost"
										size="icon"
										aria-label={`Remove email ${index + 1}`}
										onClick={() => arrayField.removeValue(index)}
									>
										<XIcon />
									</Button>
								</div>
								{isInvalid && <FieldError match>{errorMessage}</FieldError>}
							</Field>
						)
					}}
				</form.Field>
			))}
			<Button
				type="button"
				variant="outline"
				onClick={() => arrayField.pushValue({ address: "" })}
			>
				Add email
			</Button>
		</>
	)}
</form.Field>
```
