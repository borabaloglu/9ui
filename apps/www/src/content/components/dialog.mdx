## Usage

```tsx title="Imports"
import {
	Dialog,
	DialogBackdrop,
	DialogClose,
	DialogDescription,
	DialogFooter,
	DialogHeader,
	DialogPopup,
	DialogTitle,
	DialogTrigger,
} from "@/components/ui/dialog"
```

```tsx title="Anatomy"
<Dialog>
	<DialogTrigger />
	<DialogPopup>
		<DialogHeader>
			<DialogTitle />
			<DialogDescription />
		</DialogHeader>
		<DialogFooter>
			<DialogClose />
		</DialogFooter>
	</DialogPopup>
</Dialog>
```

## Examples

### Size

Set `size="sm"` on `DialogPopup` for a narrower dialog with tighter padding and equal-width footer buttons.

<ComponentPreview name="dialog-size-demo" />

### No Close Button

Set `showCloseButton={false}` on `DialogPopup` to remove the close button from the corner. The dialog still closes on Escape and on an outside press.

<ComponentPreview name="dialog-no-close-button-demo" />

### Custom Close

Render any control through `DialogClose` to close the dialog.

<ComponentPreview name="dialog-custom-close-demo" />

### Mobile Position

On small screens the dialog sits at the bottom edge. Set `showAtBottomOnMobile={false}` on `DialogPopup` to keep it centered.

The bottom padding grows by `env(safe-area-inset-bottom)`, so actions clear the home indicator when the page uses `viewport-fit=cover`.

<ComponentPreview name="dialog-mobile-position-demo" />

### Bare Footer

Set `variant="bare"` on `DialogFooter` to drop its border and background.

<ComponentPreview name="dialog-bare-footer-demo" />

### Scrollable Content

Give the content a `max-h-*` class and `overflow-y-auto` to scroll it while the header and footer stay in place.

<ComponentPreview name="dialog-scrollable-content-demo" />

### Nested

Open a dialog from inside another. The parent scales down behind the nested one.

<ComponentPreview name="dialog-nested-demo" />

## Tips

<Tips>

<Tip title="Label icon-only triggers">

Give icon-only triggers an `aria-label`.

```tsx {2}
<DialogTrigger
	render={<Button variant="outline" size="icon" aria-label="Settings" />}
>
	<SettingsIcon />
</DialogTrigger>
```

</Tip>

<Tip title="Use your own button as the trigger">

Set `render` on `DialogTrigger` to use your own button.

```tsx {1}
<DialogTrigger render={<Button variant="outline" />}>
	Edit profile
</DialogTrigger>
```

</Tip>

<Tip title="Change the corner radius">

To change the corner radius, set `className="[--dialog-radius:var(--radius-2xl)]"` on `DialogPopup`.

```tsx {1}
<DialogPopup className="[--dialog-radius:var(--radius-2xl)]">
	<DialogTitle>Edit profile</DialogTitle>
</DialogPopup>
```

</Tip>

</Tips>
