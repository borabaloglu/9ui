## Usage

```tsx title="Imports"
import { ScrollArea } from "@/components/ui/scroll-area"
```

```tsx title="Anatomy"
<ScrollArea />
```

Give `ScrollArea` a height or a max height. Scrollbars appear on hover and while scrolling, only on the axes that overflow.

## Examples

### Horizontal

Content wider than the scroll area scrolls sideways.
