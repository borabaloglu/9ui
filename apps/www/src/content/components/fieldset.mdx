## Usage

```tsx title="Imports"
import {
	Fieldset,
	FieldsetDescription,
	FieldsetLegend,
} from "@/components/ui/fieldset"
```

```tsx title="Anatomy"
<Fieldset>
	<FieldsetLegend />
	<FieldsetDescription />
	<Field />
</Fieldset>
```

## Tips

<Tips>

<Tip title="Name and describe the group">

Add a `FieldsetLegend` to name the group and a `FieldsetDescription` to describe it. Don't set `aria-labelledby` or `aria-describedby` by hand.

```tsx {2-3}
<Fieldset>
	<FieldsetLegend>Billing details</FieldsetLegend>
	<FieldsetDescription>Used on your invoices.</FieldsetDescription>
	<Field name="company">
		<FieldLabel>Company</FieldLabel>
		<Input />
	</Field>
</Fieldset>
```

</Tip>

</Tips>

## API Reference

What 9ui adds to Base UI Fieldset. See the [Base UI](https://base-ui.com/react/components/fieldset#api-reference) documentation for the rest.

### FieldsetDescription

Help text for the whole group, linked to the fieldset as its description. Renders a `<p>` element.
