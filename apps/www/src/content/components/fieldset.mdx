## Usage

```tsx title="Imports"
import {
	Fieldset,
	FieldsetDescription,
	FieldsetLegend,
} from "@/components/ui/fieldset"
```

```tsx title="Anatomy"
<Fieldset>
	<FieldsetLegend />
	<FieldsetDescription />
	<Field />
</Fieldset>
```

The legend names the group and the description is linked to it for you. Don't set `aria-labelledby` or `aria-describedby` by hand.
