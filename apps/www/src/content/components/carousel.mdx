## Usage

```tsx title="Imports"
import {
	Carousel,
	CarouselContent,
	CarouselItem,
	CarouselNext,
	CarouselPrevious,
} from "@/components/ui/carousel"
```

```tsx title="Anatomy"
<Carousel>
	<CarouselContent>
		<CarouselItem />
	</CarouselContent>
	<CarouselPrevious />
	<CarouselNext />
</Carousel>
```

## Examples

### Vertical

To scroll vertically, set `orientation="vertical"` and give `CarouselContent` a height.

<ComponentPreview name="carousel-vertical-demo" />

### Multiple

To show several slides at once, set a `basis-*` class on each `CarouselItem`.

<ComponentPreview name="carousel-multiple-demo" />

### Looped

To loop back to the first slide, set `opts={{ loop: true }}`.

<ComponentPreview name="carousel-looped-demo" />

### Dots

To build your own controls, get the carousel API with `setApi`.

<ComponentPreview name="carousel-dots-demo" />

### RTL

To show the carousel right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="carousel-rtl-demo" direction="rtl" />
