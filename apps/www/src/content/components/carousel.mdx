## Usage

```tsx title="Imports"
import {
	Carousel,
	type CarouselApi,
	CarouselContent,
	CarouselItem,
	CarouselNext,
	CarouselPrevious,
	useCarousel,
} from "@/components/ui/carousel"
```

```tsx title="Anatomy"
<Carousel>
	<CarouselContent>
		<CarouselItem />
	</CarouselContent>
	<CarouselPrevious />
	<CarouselNext />
</Carousel>
```

## Examples

### Vertical

To scroll vertically, set `orientation="vertical"` on `Carousel` and give `CarouselContent` a height.

<ComponentPreview name="carousel-vertical-demo" />

### Multiple

To show several slides at once, set a `basis-*` class on each `CarouselItem`.

<ComponentPreview name="carousel-multiple-demo" />

### Looped

To loop back to the first slide, set `opts={{ loop: true }}` on `Carousel`.

## Tips

<Tips>

<Tip title="Name the carousel for screen readers">

To name the carousel for screen readers, set `aria-label` on `Carousel`.

```tsx {1}
<Carousel aria-label="Featured products">
	<CarouselContent>
		<CarouselItem>Wireless headphones</CarouselItem>
		<CarouselItem>Mechanical keyboard</CarouselItem>
	</CarouselContent>
	<CarouselPrevious />
	<CarouselNext />
</Carousel>
```

</Tip>

</Tips>
