## Usage

```tsx title="Imports"
import {
	Combobox,
	ComboboxChip,
	ComboboxChips,
	ComboboxChipsInput,
	ComboboxClear,
	ComboboxCollection,
	ComboboxEmpty,
	ComboboxGroup,
	ComboboxGroupLabel,
	ComboboxInput,
	ComboboxInputGroup,
	ComboboxItem,
	ComboboxLabel,
	ComboboxList,
	ComboboxPopup,
	ComboboxRow,
	ComboboxSeparator,
	ComboboxStatus,
	ComboboxTrigger,
	ComboboxValue,
	createComboboxItems,
	useComboboxFilter,
	useComboboxFilteredItems,
} from "@/components/ui/combobox"
```

```tsx title="Anatomy"
<Combobox>
	<ComboboxLabel />
	<ComboboxInputGroup>
		<ComboboxInput />
		<ComboboxTrigger />
		<ComboboxClear />
	</ComboboxInputGroup>
	<ComboboxPopup>
		<ComboboxEmpty />
		<ComboboxList>
			<ComboboxGroup>
				<ComboboxGroupLabel />
				<ComboboxCollection />
			</ComboboxGroup>
			<ComboboxSeparator />
			<ComboboxItem />
		</ComboboxList>
	</ComboboxPopup>
</Combobox>
```

To let users type any text, use [Autocomplete](/docs/components/autocomplete). To pick from a short list without filtering, use [Select](/docs/components/select).

## Tips

<Tips>

<Tip title="Name the combobox">

Give every combobox a name. When the input is the control, use [Field](/docs/components/field) with a `FieldLabel` or set `aria-label` on `ComboboxInput`. When `ComboboxTrigger` is the control, add a `ComboboxLabel`.

```tsx {2}
<Combobox items={fruits}>
	<ComboboxLabel>Fruit</ComboboxLabel>
	<ComboboxTrigger render={<Button variant="outline" />}>
		<ComboboxValue />
	</ComboboxTrigger>
</Combobox>
```

</Tip>

<Tip title="Change where the popup opens">

`ComboboxPopup` takes `side`, `align`, `sideOffset` and `alignOffset` to change where the popup opens.

```tsx {1}
<ComboboxPopup side="top" align="end" sideOffset={8}>
	<ComboboxEmpty>No fruits found.</ComboboxEmpty>
</ComboboxPopup>
```

</Tip>

<Tip title="Store IDs instead of item objects">

To store IDs instead of item objects, pass `createComboboxItems(data, { getValue, getLabel })` as `items`.

```tsx {1-4,6}
const items = createComboboxItems(users, {
	getValue: (user) => user.id,
	getLabel: (user) => user.name,
})

<Combobox items={items}>
	<ComboboxInput render={<Input />} />
</Combobox>
```

</Tip>

</Tips>
