## Examples

### Outline

Set `variant="outline"` for neutral metadata, like a version or a count.

<ComponentPreview name="badge-outline-demo" />

### Secondary

Set `variant="secondary"` for a label that shouldn't draw attention.

<ComponentPreview name="badge-secondary-demo" />

### Success

Set `variant="success"` for a positive or completed status.

<ComponentPreview name="badge-success-demo" />

### Warning

Set `variant="warning"` for a status that needs attention.

<ComponentPreview name="badge-warning-demo" />

### Info

Set `variant="info"` for a neutral notice, like a new feature.

<ComponentPreview name="badge-info-demo" />

### Danger

Set `variant="danger"` for an error or a failed status.

<ComponentPreview name="badge-danger-demo" />

### Small

Set `size="sm"`, or `size="icon-sm"` for an icon-only badge.

<ComponentPreview name="badge-small-demo" />

### Default Size

Leave `size` unset, or set `size="icon"` for an icon-only badge.

<ComponentPreview name="badge-default-size-demo" />

### Large

Set `size="lg"`, or `size="icon-lg"` for an icon-only badge.

<ComponentPreview name="badge-large-demo" />

### Icon Only

Set `size="icon-sm"`, `size="icon"` or `size="icon-lg"` for a round badge that holds a single icon.

<ComponentPreview name="badge-icon-only-demo" />

### Icon

Set `data-icon` to `inline-start` or `inline-end` on the icon to tighten the padding on that side.

<ComponentPreview name="badge-icon-demo" />

### Link

Set `render={<a />}` to make the badge a link. It gains hover and focus styles.

<ComponentPreview name="badge-link-demo" />

### Button

Set `render={<button />}` to make the badge clickable.

<ComponentPreview name="badge-button-demo" />

### RTL

To enable RTL support, see the [RTL guide](/docs/getting-started/rtl).

## Tips

<Tips>

<Tip title="Label icon-only badges">

Give icon-only badges an `aria-label`.

```tsx {1}
<Badge size="icon" variant="success" aria-label="Approved">
	<CheckIcon />
</Badge>
```

</Tip>

</Tips>
