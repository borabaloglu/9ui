## Usage

```tsx title="Imports"
import {
	Sheet,
	SheetBackdrop,
	SheetClose,
	SheetDescription,
	SheetFooter,
	SheetHeader,
	SheetPanel,
	SheetPopup,
	SheetTitle,
	SheetTrigger,
} from "@/components/ui/sheet"
```

```tsx title="Anatomy"
<Sheet>
	<SheetTrigger />
	<SheetPopup>
		<SheetHeader>
			<SheetTitle />
			<SheetDescription />
		</SheetHeader>
		<SheetPanel />
		<SheetFooter>
			<SheetClose />
		</SheetFooter>
	</SheetPopup>
</Sheet>
```

## Examples

### Side

Set `side` on `SheetPopup` to choose the edge the sheet slides in from.

<ComponentPreview name="sheet-side-demo" />

### Inset

Set `variant="inset"` on `SheetPopup` to float the sheet inside the viewport with rounded corners. On small screens it stays attached to the edge.

<ComponentPreview name="sheet-inset-demo" />

### Close Button

Set `showCloseButton={false}` on `SheetPopup` to remove the close button from the corner. The sheet still closes on Escape and on an outside press.

<ComponentPreview name="sheet-close-button-demo" />

## Tips

<Tips>

<Tip title="Label icon-only triggers">

Give icon-only triggers an `aria-label`.

```tsx {2}
<SheetTrigger
	render={<Button variant="outline" size="icon" aria-label="Settings" />}
>
	<SettingsIcon />
</SheetTrigger>
```

</Tip>

<Tip title="Use your own button as the trigger">

Set `render` on `SheetTrigger` to use your own button.

```tsx {1}
<SheetTrigger render={<Button variant="outline" />}>
	Edit profile
</SheetTrigger>
```

</Tip>

<Tip title="Scroll the body">

Put the body in `SheetPanel`. It scrolls when the content is taller than the sheet, while the header and footer stay in place.

```tsx {5-7}
<SheetPopup>
	<SheetHeader>
		<SheetTitle>Terms of service</SheetTitle>
	</SheetHeader>
	<SheetPanel>
		<p>By using this service you agree to these terms.</p>
	</SheetPanel>
	<SheetFooter>
		<SheetClose render={<Button />}>Accept</SheetClose>
	</SheetFooter>
</SheetPopup>
```

</Tip>

<Tip title="Clear the status bar and home indicator">

To keep content clear of the status bar and home indicator, set `viewport-fit=cover` in the viewport meta tag of the page.

```tsx {3}
<meta
	name="viewport"
	content="width=device-width, initial-scale=1, viewport-fit=cover"
/>
```

</Tip>

<Tip title="Change the corner radius">

To change the corner radius of an inset sheet, set `className="[--sheet-radius:var(--radius-xl)]"` on `SheetPopup`.

```tsx {1}
<SheetPopup variant="inset" className="[--sheet-radius:var(--radius-xl)]">
	<SheetTitle>Edit profile</SheetTitle>
</SheetPopup>
```

</Tip>

</Tips>
