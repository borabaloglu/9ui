## Usage

```tsx title="Imports"
import {
	Sheet,
	SheetClose,
	SheetDescription,
	SheetFooter,
	SheetHeader,
	SheetPanel,
	SheetPopup,
	SheetTitle,
	SheetTrigger,
} from "@/components/ui/sheet"
```

```tsx title="Anatomy"
<Sheet>
	<SheetTrigger />
	<SheetPopup>
		<SheetHeader>
			<SheetTitle />
			<SheetDescription />
		</SheetHeader>
		<SheetPanel />
		<SheetFooter>
			<SheetClose />
		</SheetFooter>
	</SheetPopup>
</Sheet>
```

Put the body in `SheetPanel`. It scrolls when the content is taller than the sheet, while the header and footer stay in place.

The sheet pads its top and bottom by `env(safe-area-inset-top)` and `env(safe-area-inset-bottom)`, so content clears the status bar and home indicator when the page uses `viewport-fit=cover`.

To change the corner radius of an inset sheet, set `className="[--sheet-radius:var(--radius-xl)]"` on `SheetPopup`.

## Examples

### Side

Set `side` on `SheetPopup` to choose the edge the sheet slides in from.

<ComponentPreview name="sheet-side-demo" />

### Inset

Set `variant="inset"` on `SheetPopup` to float the sheet inside the viewport with rounded corners. On small screens it stays attached to the edge.

<ComponentPreview name="sheet-inset-demo" />

### Close Button

Set `showCloseButton={false}` on `SheetPopup` to remove the close button from the corner. The sheet still closes on Escape and on an outside press.

### Bare Footer

Set `variant="bare"` on `SheetFooter` to drop its border and background.
