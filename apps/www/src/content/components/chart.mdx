## About

Chart is a thin layer over [Recharts](https://recharts.org). You build the chart with Recharts components and add `ChartContainer`, `ChartTooltip` and `ChartLegend` where you need them.

Recharts is not wrapped, so every Recharts prop and component still works.

## Usage

```tsx title="Imports"
import { Bar, BarChart } from "recharts"

import {
	type ChartConfig,
	ChartContainer,
	ChartLegend,
	ChartLegendContent,
	ChartTooltip,
	ChartTooltipContent,
} from "@/components/ui/chart"
```

```tsx title="Anatomy"
<ChartContainer config={chartConfig}>
	<BarChart data={chartData}>
		<ChartTooltip content={<ChartTooltipContent />} />
		<ChartLegend content={<ChartLegendContent />} />
		<Bar dataKey="desktop" fill="var(--color-desktop)" />
	</BarChart>
</ChartContainer>
```

## Your First Chart

This section builds a bar chart step by step.

### Data and config

Start with the data and a config. The data can have any shape. The config gives each series a label and a color.

```tsx
const chartData = [
	{ month: "Jan", desktop: 186, mobile: 80 },
	{ month: "Feb", desktop: 305, mobile: 200 },
	{ month: "Mar", desktop: 237, mobile: 120 },
]

const chartConfig = {
	desktop: {
		label: "Desktop",
		color: "var(--chart-1)",
	},
	mobile: {
		label: "Mobile",
		color: "var(--chart-2)",
	},
} satisfies ChartConfig
```

## Config

The config holds the label, icon and color of each series. It is separate from the data, so several charts can share one config.

```tsx
import { MonitorIcon } from "lucide-react"

const chartConfig = {
	desktop: {
		label: "Desktop",
		icon: MonitorIcon,
		color: "var(--chart-1)",
	},
} satisfies ChartConfig
```

## Theming

### Colors

The theme has five chart colors, `chart-1` through `chart-5`. They are shades of one hue, with separate values for light and dark.

To use a theme color, set `color` to `var(--chart-1)`. Any CSS color works too.

```tsx
const chartConfig = {
	desktop: {
		label: "Desktop",
		color: "var(--chart-1)",
	},
	mobile: {
		label: "Mobile",
		color: "oklch(70.7% 0.165 254.624)",
	},
} satisfies ChartConfig
```

To use one color in light and another in dark, set `theme` instead of `color`.

### Using colors

Each key in the config becomes a `--color-<key>` variable inside the chart.

To color a Recharts component, set `fill` or `stroke`.

```tsx
<Bar dataKey="desktop" fill="var(--color-desktop)" />
```

To color a single data point, set `fill` in the data.

```tsx
const chartData = [
	{ browser: "chrome", visitors: 275, fill: "var(--color-chrome)" },
	{ browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]
```

To color your own elements, use the variable in a class.

```tsx
<span className="text-(--color-desktop)">Desktop</span>
```

## Tooltip

`ChartTooltip` is the Recharts tooltip. `ChartTooltipContent` renders its content.

| Prop | Type | Description |
| --- | --- | --- |
| `indicator` | `dot`, `line` or `dashed` | The marker next to each row. |
| `hideLabel` | `boolean` | Hides the label. |
| `hideIndicator` | `boolean` | Hides the marker. |
| `nameKey` | `string` | The config or data key to read row names from. |
| `labelKey` | `string` | The config or data key to read the label from. |
| `formatter` | `function` | Renders each row. |
| `labelFormatter` | `function` | Renders the label. |

## Legend

`ChartLegend` is the Recharts legend. `ChartLegendContent` renders its content. Items keep the order of the series.

| Prop | Type | Description |
| --- | --- | --- |
| `nameKey` | `string` | The config or data key to read item names from. |
| `hideIcon` | `boolean` | Shows the color marker in place of the config icon. |

Set `icon` in the config to show an icon next to each label. Set `verticalAlign` on `ChartLegend` to `top` to move the legend above the chart.

## Accessibility

Recharts adds keyboard navigation and screen reader support to charts by default. To turn it off, set `accessibilityLayer` to `false` on the chart.

Charts respect the reduced motion setting.

## Upgrading to Recharts 3

Chart uses Recharts 3. When you update charts written for Recharts 2:

- Use `var(--chart-1)`, not `hsl(var(--chart-1))`.
- Keep a height or an aspect ratio on `ChartContainer`.
- Remove `layout` from `Bar` when `BarChart` already sets it.
- Remove `accessibilityLayer`. It is on by default.

### RTL

To show the chart right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. Set `reversed` on `XAxis` and `orientation="right"` on `YAxis` too. See [RTL](/docs/getting-started/rtl).

Bars in a group keep their left to right order. This comes from Recharts.
