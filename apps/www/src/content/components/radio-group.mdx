## Usage

```tsx title="Imports"
import { Radio, RadioGroup, RadioGroupLabel } from "@/components/ui/radio-group"
```

```tsx title="Anatomy"
<RadioGroup>
	<RadioGroupLabel />
	<Radio />
</RadioGroup>
```

## Examples

### Disabled

Set `disabled` on `RadioGroup` to prevent interaction with every radio in it.

<ComponentPreview name="radio-group-disabled-demo" />

### Disabled Item

Set `disabled` on a `Radio` to turn off a single option.

<ComponentPreview name="radio-group-disabled-item-demo" />

### Invalid

Set `invalid` on `Field` to show the error state, and clear it once an option is picked. Outside a `Field`, set `aria-invalid` on each radio.

<ComponentPreview name="radio-group-invalid-demo" showReload={true} />

### Field

Inside [Field](/docs/components/field), wrap each option in `FieldItem` to give it its own `FieldLabel` and `FieldDescription`.

<ComponentPreview name="radio-group-field-demo" />

### Choice Card

Wrap the radio and its text in `FieldLabel` to make the whole card clickable. Style the selected card with `has-data-checked`.

<ComponentPreview name="radio-group-choice-card-demo" />

### RTL

To enable RTL support, see the [RTL guide](/docs/getting-started/rtl).
