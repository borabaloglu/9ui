## Usage

```tsx title="Imports"
import { Radio, RadioGroup, RadioGroupLabel } from "@/components/ui/radio-group"
```

```tsx title="Anatomy"
<RadioGroup>
	<RadioGroupLabel />
	<Radio />
</RadioGroup>
```

## Tips

<Tips>

<Tip title="Label each radio">

Give each `Radio` a visible label. Place it inside [Label](/docs/components/label).

```tsx {2,5}
<RadioGroup defaultValue="standard">
	<Label>
		<Radio value="standard" />
		Standard
	</Label>
</RadioGroup>
```

</Tip>

<Tip title="Name the group">

To name the group, set an `id` on `RadioGroupLabel` and pass it to `aria-labelledby` on `RadioGroup`.

```tsx {1-2}
<RadioGroup aria-labelledby="plan-label">
	<RadioGroupLabel id="plan-label">Plan</RadioGroupLabel>
	<Label>
		<Radio value="standard" />
		Standard
	</Label>
</RadioGroup>
```

</Tip>

<Tip title="Give each radio a value">

Give each `Radio` a `value`.

```tsx {3,7}
<RadioGroup defaultValue="standard">
	<Label>
		<Radio value="basic" />
		Basic
	</Label>
	<Label>
		<Radio value="standard" />
		Standard
	</Label>
</RadioGroup>
```

</Tip>

<Tip title="Add a description or an error message">

Use [Field](/docs/components/field) when a radio also needs a description or an error message.

```tsx {1,3,8}
<Field name="plan">
	<RadioGroup defaultValue="standard">
		<FieldItem>
			<FieldLabel>
				<Radio value="standard" />
				Standard
			</FieldLabel>
			<FieldDescription>Great for growing teams.</FieldDescription>
		</FieldItem>
	</RadioGroup>
</Field>
```

</Tip>

</Tips>
