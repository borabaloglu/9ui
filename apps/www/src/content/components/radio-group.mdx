## Usage

```tsx title="Imports"
import { Radio, RadioGroup, RadioGroupLabel } from "@/components/ui/radio-group"
```

```tsx title="Anatomy"
<RadioGroup>
	<RadioGroupLabel />
	<Radio />
</RadioGroup>
```

Give each `Radio` a `value` and a visible label. Place it inside [Label](/docs/components/label), or use [Field](/docs/components/field) when it also needs a description or an error message. Name the group by giving `RadioGroupLabel` an `id` and passing it to `aria-labelledby`.
