## Installation

<ComponentInstallation>
<div>
```bash title="Terminal"
npx shadcn@latest add @9ui/skeleton
```
</div>

<Steps>

<Step>Copy and paste the following code into your project.</Step>

<ComponentSource name="skeleton" />

<Step>Add the animation to your CSS file.</Step>

```css title="globals.css"
@theme inline {
	--animate-skeleton: skeleton 2s -1s infinite linear;

	@keyframes skeleton {
		to {
			background-position: -200% 0;
		}
	}
}
```

</Steps>
</ComponentInstallation>

## Usage

```tsx title="Imports"
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx title="Anatomy"
<Skeleton />
```

Set the size and shape with `className`. To tell screen readers the content is loading, set `aria-busy` on the container.
