<ComponentInstallation>
<div>
```bash title="Terminal"
npx shadcn@latest add @9ui/skeleton
```
</div>

<Steps>

<Step>Copy and paste the following code into your project.</Step>

<ComponentSource name="skeleton" />

<Step>Add the animation to your CSS file.</Step>

```css title="globals.css"
@theme inline {
	--animate-skeleton: skeleton 2s -1s infinite linear;

	@keyframes skeleton {
		to {
			background-position: -200% 0;
		}
	}
}
```

</Steps>
</ComponentInstallation>

## Usage


## Tips

<Tips>

<Tip title="Tell screen readers the content is loading">

To tell screen readers the content is loading, set `aria-busy="true"` on the container.

```tsx {1}
<div className="flex flex-col gap-1.5" aria-busy="true">
	<Skeleton className="h-4 w-32" />
	<Skeleton className="h-3 w-24" />
</div>
```

</Tip>

<Tip title="Set the size and shape">

Set `className` on `Skeleton` to change its size and shape.

```tsx {1}
<Skeleton className="size-10 rounded-full" />
```

</Tip>

</Tips>

## API Reference

Skeleton is built by 9ui, so this is its full API. It takes the props of a `div` element and adds none of its own.
