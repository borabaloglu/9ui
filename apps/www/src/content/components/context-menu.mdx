## Usage

```tsx title="Imports"
import {
	ContextMenu,
	ContextMenuCheckboxItem,
	ContextMenuGroup,
	ContextMenuGroupLabel,
	ContextMenuItem,
	ContextMenuLinkItem,
	ContextMenuPopup,
	ContextMenuRadioGroup,
	ContextMenuRadioItem,
	ContextMenuSeparator,
	ContextMenuShortcut,
	ContextMenuSub,
	ContextMenuSubPopup,
	ContextMenuSubTrigger,
	ContextMenuTrigger,
} from "@/components/ui/context-menu"
```

```tsx title="Anatomy"
<ContextMenu>
	<ContextMenuTrigger />
	<ContextMenuPopup>
		<ContextMenuGroup>
			<ContextMenuGroupLabel />
			<ContextMenuItem>
				<ContextMenuShortcut />
			</ContextMenuItem>
			<ContextMenuLinkItem />
		</ContextMenuGroup>
		<ContextMenuSeparator />
		<ContextMenuCheckboxItem />
		<ContextMenuRadioGroup>
			<ContextMenuRadioItem />
		</ContextMenuRadioGroup>
		<ContextMenuSub>
			<ContextMenuSubTrigger />
			<ContextMenuSubPopup>
				<ContextMenuItem />
			</ContextMenuSubPopup>
		</ContextMenuSub>
	</ContextMenuPopup>
</ContextMenu>
```

## Examples

### Groups

Wrap related items in `ContextMenuGroup` and name them with `ContextMenuGroupLabel`.

<ComponentPreview name="context-menu-groups-demo" />

### Shortcut

Add `ContextMenuShortcut` inside an item to show its keyboard shortcut. It is a hint only, so bind the keys yourself.

<ComponentPreview name="context-menu-shortcut-demo" />

### Icons

Place an icon before the item text.

<ComponentPreview name="context-menu-icons-demo" />

### Checkbox

Use `ContextMenuCheckboxItem` for options that turn on and off. The menu stays open when one is toggled. Set `inset` on plain items to line them up with checkbox items.

<ComponentPreview name="context-menu-checkbox-demo" />

### Checkbox with Icons

Place an icon before the text of a `ContextMenuCheckboxItem`.

<ComponentPreview name="context-menu-checkbox-with-icons-demo" />

### Radio Group

Use `ContextMenuRadioGroup` and `ContextMenuRadioItem` to pick one option from a set.

<ComponentPreview name="context-menu-radio-group-demo" />

### Radio Group with Icons

Place an icon before the text of a `ContextMenuRadioItem`.

<ComponentPreview name="context-menu-radio-group-with-icons-demo" />

### Destructive

Set `variant="destructive"` on `ContextMenuItem` for an action that deletes or can't be undone.

<ComponentPreview name="context-menu-destructive-demo" />

### Link

Use `ContextMenuLinkItem` for items that go to another page. It renders an `<a>`.

<ComponentPreview name="context-menu-link-demo" />

### Submenu

Nest `ContextMenuSub`, `ContextMenuSubTrigger` and `ContextMenuSubPopup` to open a second level.

<ComponentPreview name="context-menu-submenu-demo" />

### Complex
