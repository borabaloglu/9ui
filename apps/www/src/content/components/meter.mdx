## Usage

```tsx title="Imports"
import {
	Meter,
	MeterCircularIndicator,
	MeterCircularTrack,
	MeterIndicator,
	MeterLabel,
	MeterTrack,
	MeterValue,
} from "@/components/ui/meter"
```

```tsx title="Anatomy"
<Meter>
	<MeterLabel />
	<MeterValue />
	<MeterTrack>
		<MeterIndicator />
	</MeterTrack>
</Meter>
```

Give every meter a name: add a `MeterLabel`, or set `aria-label` on `Meter` when there is no visible label.

## Examples

### Without Label

Leave out `MeterLabel` and `MeterValue` to show only the bar.

<ComponentPreview name="meter-without-label-demo" />

### Format

Set `format` to show the value as a unit, currency or percentage. It takes the same options as `Intl.NumberFormat`.

<ComponentPreview name="meter-format-demo" />

### Custom Value

To write the value text yourself, pass a function to `MeterValue`. Set `getAriaValueText` so screen readers hear the same text.

<ComponentPreview name="meter-custom-value-demo" />

### Range

Set `min` and `max` to change the scale.

<ComponentPreview name="meter-range-demo" />

### Thresholds

To color the fill by how good the value is, set `low`, `high` and `optimum`. They work like the native `meter` element.

<ComponentPreview name="meter-thresholds-demo" />

### Color

Set `className` on `MeterIndicator` to change the fill color.

<ComponentPreview name="meter-color-demo" />

### Circular

To show a ring instead of a bar, use `MeterCircularTrack` and `MeterCircularIndicator`. Set `size` and `strokeWidth` on `MeterCircularTrack` to change its dimensions.

<ComponentPreview name="meter-circular-demo" />

### RTL

To show the meter right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="meter-rtl-demo" direction="rtl" />

## API Reference

What 9ui adds to Base UI Meter. For the rest of the API, see the [Base UI Meter reference](https://base-ui.com/react/components/meter#api-reference).

### Meter

Set `low` or `high` to color the fill by level. They work like the native `meter` element.
