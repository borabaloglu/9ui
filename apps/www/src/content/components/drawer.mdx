## About

Drawer is built on the Base UI drawer. The `vaul-base` drawer that used to be installed as `drawer` now lives at [Vaul](/docs/components/vaul), with the same parts under `Vaul*` names.

## Usage

```tsx title="Imports"
import {
	createDrawerHandle,
	Drawer,
	DrawerBackdrop,
	DrawerClose,
	DrawerDescription,
	DrawerFooter,
	DrawerHeader,
	DrawerIndent,
	DrawerIndentBackground,
	DrawerPanel,
	DrawerPopup,
	DrawerProvider,
	DrawerSwipeArea,
	DrawerTitle,
	DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx title="Anatomy"
<Drawer>
	<DrawerTrigger />
	<DrawerPopup>
		<DrawerHeader>
			<DrawerTitle />
			<DrawerDescription />
		</DrawerHeader>
		<DrawerPanel />
		<DrawerFooter>
			<DrawerClose />
		</DrawerFooter>
	</DrawerPopup>
</Drawer>
```

On top and bottom drawers the header, panel and footer keep their content in a centered column, so it stays readable on wide screens.

If you don't need swipe gestures or snap points, use [Sheet](/docs/components/sheet).

## Examples

### Swipe Direction

Set `swipeDirection` on `Drawer` to choose the direction that dismisses the drawer. The drawer sits on that edge: `down` is a bottom drawer, `up` a top drawer, `left` and `right` are side drawers.

<ComponentPreview name="drawer-swipe-direction-demo" />

### Inset

Set `variant="inset"` on `DrawerPopup` to float the drawer inside the viewport with rounded corners on every side. Inset drawers aren't meant to be combined with snap points.

<ComponentPreview name="drawer-inset-demo" />

### Scrollable Content

Put long content in `DrawerPanel`. To cap the height, set a `max-h-*` class on `DrawerPopup`.

<ComponentPreview name="drawer-scrollable-content-demo" />

### Snap Points

Set `snapPoints` on `Drawer` to let a bottom drawer rest at fixed heights. Use pixel or rem strings, or a fraction of the viewport height, and control the current one with `snapPoint` and `onSnapPointChange`. The backdrop stays half visible at the lower snap points and fades in fully as the drawer expands.

<ComponentPreview name="drawer-snap-points-demo" />

### Nested

Render a `Drawer` inside another to stack them. The parent scales down behind the nested one and follows it while it is swiped away.

<ComponentPreview name="drawer-nested-demo" />

### Bare Footer

Set `variant="bare"` on `DrawerFooter` to drop its border and background.

<ComponentPreview name="drawer-bare-footer-demo" />

### Non-Modal

Set `modal={false}` on `Drawer` to leave the page behind usable: there is no backdrop, focus isn't trapped and the page still scrolls. Add `disablePointerDismissal` to keep the drawer open when something outside is pressed.

<ComponentPreview name="drawer-non-modal-demo" />

### Swipe to Open

Place `DrawerSwipeArea` inside `Drawer` to open the drawer by swiping in from its edge. The area is an invisible strip along that edge of the screen.

The example below runs in a sandbox: the drawer is rendered into the frame with `portalProps.container`, and the strip is tinted so you can see it. In your app the strip sits on the edge of the screen.

<ComponentPreview name="drawer-swipe-to-open-demo" />

### Detached Triggers

Create a handle with `createDrawerHandle` and pass it to `Drawer` and to any `DrawerTrigger` outside it. Give each trigger a `payload` and read it from the function passed as the child of `Drawer`.

<ComponentPreview name="drawer-detached-triggers-demo" />

### Scale Background

Wrap your app in `DrawerProvider` and put `DrawerIndentBackground` and `DrawerIndent` at the top of the tree to scale the page down while a drawer is open. Every `Drawer` inside the provider triggers it, and the page follows the drawer as it is swiped away.

```tsx
<DrawerProvider>
	<DrawerIndentBackground />
	<DrawerIndent>{children}</DrawerIndent>
</DrawerProvider>
```

`DrawerIndent` is the page: it carries the page background and clips its content to the rounded corners. While a drawer is open, `position: fixed` elements inside it are positioned against it instead of the viewport. With reduced motion the page stays in place.

The example below runs in a sandbox: the drawer is rendered into the frame with `portalProps.container`, and the frame holds the indent. In your app the indent is the page itself.

<ComponentPreview name="drawer-scale-background-demo" />

## Tips

<Tips>

<Tip title="Label icon-only triggers">

Give icon-only triggers an `aria-label`.

```tsx {2}
<DrawerTrigger
	render={<Button variant="outline" size="icon" aria-label="Settings" />}
>
	<SettingsIcon />
</DrawerTrigger>
```

</Tip>

<Tip title="Use your own button as the trigger">

Set `render` on `DrawerTrigger` to use your own button.

```tsx {1}
<DrawerTrigger render={<Button variant="outline" />}>
	Send feedback
</DrawerTrigger>
```

</Tip>

<Tip title="Scroll the body">

Put the body in `DrawerPanel`. It scrolls when the content is taller than the drawer, while the header and footer stay in place. With a mouse, text inside the panel can be selected, and the drawer is dragged by its header, footer or handle.

```tsx {5-7}
<DrawerPopup>
	<DrawerHeader>
		<DrawerTitle>Terms of service</DrawerTitle>
	</DrawerHeader>
	<DrawerPanel>
		<p>By using this service you agree to these terms.</p>
	</DrawerPanel>
	<DrawerFooter>
		<DrawerClose render={<Button />}>Accept</DrawerClose>
	</DrawerFooter>
</DrawerPopup>
```

</Tip>

<Tip title="Clear the status bar and home indicator">

To keep content clear of the status bar and home indicator, set `viewport-fit=cover` in the viewport meta tag of the page.

```tsx {3}
<meta
	name="viewport"
	content="width=device-width, initial-scale=1, viewport-fit=cover"
/>
```

</Tip>

<Tip title="Change the corner radius">

To change the corner radius, set `className="[--drawer-radius:var(--radius-xl)]"` on `DrawerPopup`.

```tsx {1}
<DrawerPopup className="[--drawer-radius:var(--radius-xl)]">
	<DrawerTitle>Send feedback</DrawerTitle>
</DrawerPopup>
```

</Tip>

<Tip title="Hide the handle">

The handle shows on top and bottom drawers. To remove it, set `showHandle={false}` on `DrawerPopup`.

```tsx {1}
<DrawerPopup showHandle={false}>
	<DrawerPanel>Content</DrawerPanel>
</DrawerPopup>
```

</Tip>

</Tips>
