## Examples

### Vertical

Set `orientation="vertical"` to divide items in a row. The separator stretches to the height of a flex row. Set an `h-*` class for a fixed height.

## Tips

<Tips>

<Tip title="Hide a decorative separator from screen readers">

Set `aria-hidden` on `Separator` when it is only decorative.

```tsx {3}
<div className="flex gap-3 text-sm">
	<span>Account</span>
	<Separator orientation="vertical" aria-hidden />
	<span>Billing</span>
</div>
```

</Tip>

</Tips>
