## Usage

```tsx title="Imports"
import { Button } from "@/components/ui/button"
```

```tsx title="Anatomy"
<Button />
```

Give icon-only buttons an `aria-label`. Set `type="submit"` to submit a form.

A button isn't a link. For navigation, put `buttonVariants()` on an `<a>`.
