## Usage

```tsx title="Imports"
import { Checkbox } from "@/components/ui/checkbox"
```

```tsx title="Anatomy"
<Checkbox />
```

Give every checkbox a visible label. Place it inside [Label](/docs/components/label), or use [Field](/docs/components/field) when it also needs a description or an error message.

## Examples

### Indeterminate

Set `indeterminate` to show a mixed state, such as a "select all" box when only some items are checked. Use [Checkbox Group](/docs/components/checkbox-group) to manage it for you.

<ComponentPreview name="checkbox-indeterminate-demo" />

### Description

Use `Field` with `FieldDescription` to add help text under the label.

<ComponentPreview name="checkbox-description-demo" />

### Disabled

Set `disabled` to prevent interaction. A `Label` around the checkbox dims with it.

<ComponentPreview name="checkbox-disabled-demo" />

### Invalid

Set `invalid` on `Field` to show the error state, and clear it once the box is checked. Outside a `Field`, set `aria-invalid` on the checkbox.

<ComponentPreview name="checkbox-invalid-demo" />

### Choice Card

Wrap the checkbox and its text in `FieldLabel` to make the whole card clickable. Style the checked card with `data-filled`.

<ComponentPreview name="checkbox-choice-card-demo" />
