## Usage

```tsx title="Imports"
import {
	createPreviewCardHandle,
	PreviewCard,
	PreviewCardPanel,
	PreviewCardPopup,
	PreviewCardTrigger,
	PreviewCardViewport,
} from "@/components/ui/preview-card"
```

```tsx title="Anatomy"
<PreviewCard>
	<PreviewCardTrigger />
	<PreviewCardPopup />
</PreviewCard>
```

`PreviewCardTrigger` is a link. Set `href` on it.

Set `delay` and `closeDelay` on `PreviewCardTrigger` to change how fast the preview card opens and closes.

The preview card does not open on touch or for screen readers. Keep everything it shows available on the linked page.

## Examples

### Side

Set `side` on `PreviewCardPopup` to change where the preview card opens. It also takes `align`, `sideOffset` and `alignOffset`.

<ComponentPreview name="preview-card-side-demo" />

### Arrow

Set `arrow` on `PreviewCardPopup` to point at the trigger.

Wrap the content in `PreviewCardPanel` to scroll it when the preview card has an arrow.

<ComponentPreview name="preview-card-arrow-demo" />

### Detached Triggers

Create a handle with `createPreviewCardHandle` and pass it to `PreviewCard` and to any `PreviewCardTrigger` outside it. Give each trigger a `payload` and read it from the function passed as the child of `PreviewCard`.

Wrap the content in `PreviewCardViewport` to animate the preview card between triggers.
