## Usage

```tsx title="Imports"
import {
	createPreviewCardHandle,
	PreviewCard,
	PreviewCardPanel,
	PreviewCardPopup,
	PreviewCardTrigger,
	PreviewCardViewport,
} from "@/components/ui/preview-card"
```

```tsx title="Anatomy"
<PreviewCard>
	<PreviewCardTrigger />
	<PreviewCardPopup />
</PreviewCard>
```

The preview card doesn't open on touch or for screen readers. Keep everything it shows available on the linked page.

## Examples

### Side

Set `side` on `PreviewCardPopup` to change where the preview card opens. It also takes `align`, `sideOffset` and `alignOffset`.

<ComponentPreview name="preview-card-side-demo" />

### Arrow

Set `showArrow` on `PreviewCardPopup` to point at the trigger.

<ComponentPreview name="preview-card-arrow-demo" />

### Detached Triggers

Create a handle with `createPreviewCardHandle` and pass it to `PreviewCard` and to any `PreviewCardTrigger` outside it. Give each trigger a `payload` and read it from the function passed as the child of `PreviewCard`.

Wrap the content in `PreviewCardViewport` to animate the preview card between triggers.

## Tips

<Tips>

<Tip title="Set where the trigger links to">

`PreviewCardTrigger` is a link. Set `href` on it.

```tsx {1}
<PreviewCardTrigger href="https://www.9ui.dev">
	9ui
</PreviewCardTrigger>
```

</Tip>

<Tip title="Change the open and close delay">

Set `delay` and `closeDelay` on `PreviewCardTrigger` to change how fast the preview card opens and closes.

```tsx {3-4}
<PreviewCardTrigger
	href="https://www.9ui.dev"
	delay={200}
	closeDelay={100}
>
	9ui
</PreviewCardTrigger>
```

</Tip>

<Tip title="Change the corner radius">

To change the corner radius, set `className="[--preview-card-radius:var(--radius-xl)]"` on `PreviewCardPopup`.

```tsx {1}
<PreviewCardPopup className="[--preview-card-radius:var(--radius-xl)]">
	<span className="font-medium">9ui.dev</span>
</PreviewCardPopup>
```

</Tip>

</Tips>
