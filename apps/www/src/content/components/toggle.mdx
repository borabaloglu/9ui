## Usage

```tsx title="Imports"
import { Toggle } from "@/components/ui/toggle"
```

```tsx title="Anatomy"
<Toggle />
```

Give an icon-only toggle an `aria-label`.

## Examples

### Outline

Set `variant="outline"` for a bordered toggle.

<ComponentPreview name="toggle-outline-demo" />

### Sizes

Set `size` to `sm` or `lg` to change the size. A toggle with only an icon is square.

<ComponentPreview name="toggle-sizes-demo" />

### Controlled

To control the toggle, set `pressed` and `onPressedChange`.

<ComponentPreview name="toggle-controlled-demo" />

### Disabled

Set `disabled` to prevent interaction.

<ComponentPreview name="toggle-disabled-demo" />

### RTL

To show the toggle right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="toggle-rtl-demo" direction="rtl" />
