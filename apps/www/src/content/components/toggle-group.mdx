## Usage

```tsx title="Imports"
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

```tsx title="Anatomy"
<ToggleGroup>
	<ToggleGroupItem />
</ToggleGroup>
```

Give the group an `aria-label`, and each icon-only item its own.

## Examples

### Outline

Set `variant="outline"` on `ToggleGroup` for bordered items that are joined together.

### Multiple

### Sizes

Set `size` on `ToggleGroup` to `sm` or `lg` to change the size of every item.

To change the gap between items, set `spacing` on `ToggleGroup`. Set `spacing={0}` to join them.
