## Usage

```tsx title="Imports"
import {
	AlertDialog,
	AlertDialogClose,
	AlertDialogDescription,
	AlertDialogFooter,
	AlertDialogHeader,
	AlertDialogPopup,
	AlertDialogTitle,
	AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
```

```tsx title="Anatomy"
<AlertDialog>
	<AlertDialogTrigger />
	<AlertDialogPopup>
		<AlertDialogHeader>
			<AlertDialogTitle />
			<AlertDialogDescription />
		</AlertDialogHeader>
		<AlertDialogFooter>
			<AlertDialogClose />
		</AlertDialogFooter>
	</AlertDialogPopup>
</AlertDialog>
```

To change the corner radius, set `className="[--alert-dialog-radius:var(--radius-2xl)]"` on `AlertDialogPopup`.

## Examples

### Sizes

Set `size="sm"` on `AlertDialogPopup` for a narrower dialog with tighter padding, a centered header and equal-width footer buttons.

<ComponentPreview name="alert-dialog-sm-demo" />

### Icon

Place an icon in `AlertDialogMedia` at the top of `AlertDialogHeader` to signal the kind of action.

<ComponentPreview name="alert-dialog-icon-demo" />

### Mobile Position

On small screens the alert dialog sits at the bottom edge. Set `showAtBottomOnMobile={false}` on `AlertDialogPopup` to keep it centered.

The bottom padding grows by `env(safe-area-inset-bottom)`, so actions clear the home indicator when the page uses `viewport-fit=cover`.

<ComponentPreview name="alert-dialog-mobile-bottom-off-demo" />

### Bare Footer

Set `variant="bare"` on `AlertDialogFooter` to drop its border and background.

<ComponentPreview name="alert-dialog-footer-bare-demo" />

### Close Confirmation

Open an alert dialog from a dialog to confirm before unsaved changes are discarded.

<ComponentPreview name="alert-dialog-close-confirmation-demo" />

### RTL

To show the alert dialog right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="alert-dialog-rtl-demo" direction="rtl" />
