## Usage

```tsx title="Imports"
import {
	AlertDialog,
	AlertDialogClose,
	AlertDialogDescription,
	AlertDialogFooter,
	AlertDialogHeader,
	AlertDialogPopup,
	AlertDialogTitle,
	AlertDialogTrigger,
} from "@/components/ui/alert-dialog"
```

```tsx title="Anatomy"
<AlertDialog>
	<AlertDialogTrigger />
	<AlertDialogPopup>
		<AlertDialogHeader>
			<AlertDialogTitle />
			<AlertDialogDescription />
		</AlertDialogHeader>
		<AlertDialogFooter>
			<AlertDialogClose />
		</AlertDialogFooter>
	</AlertDialogPopup>
</AlertDialog>
```

To change the corner radius, set `className="[--alert-dialog-radius:var(--radius-2xl)]"` on `AlertDialogPopup`.

## Examples

### Sizes

Set `size="sm"` on `AlertDialogPopup` for a narrower dialog with tighter padding, a centered header and equal-width footer buttons.

<ComponentPreview name="alert-dialog-sm-demo" />

### Icon

Place an icon in `AlertDialogMedia` at the top of `AlertDialogHeader` to signal the kind of action.

<ComponentPreview name="alert-dialog-icon-demo" />

### Mobile Position

On small screens the alert dialog sits at the bottom edge. Set `showAtBottomOnMobile={false}` on `AlertDialogPopup` to keep it centered.

The bottom padding grows by `env(safe-area-inset-bottom)`, so actions clear the home indicator when the page uses `viewport-fit=cover`.
