## Tips

<Tips>

<Tip title="Hide the spinner next to loading text">

Set `aria-hidden` on `Spinner` when it sits next to loading text.

```tsx {2}
<div className="flex items-center gap-2 text-sm">
	<Spinner aria-hidden />
	Loading
</div>
```

</Tip>

</Tips>

## API Reference

Spinner is built by 9ui, so this is its full API. It takes the props of a Lucide icon, except `size`, and adds none of its own.
