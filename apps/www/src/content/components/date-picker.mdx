## Installation

The date picker component is a composition of the `Calendar` and `Popover` components.

<Steps>

<Step>Follow the installation instructions for the [Calendar](/docs/components/calendar) and [Popover](/docs/components/popover) components.</Step>

<Step>Add the components your picker uses. The demos on this page use [Button](/docs/components/button), [Field](/docs/components/field) and [Input Group](/docs/components/input-group).</Step>

<Step>Install the dependencies.</Step>

```bash title="Terminal"
npm install date-fns
```

</Steps>

## Usage

```tsx title="Imports"
import { Calendar } from "@/components/ui/calendar"
import {
	Popover,
	PopoverPopup,
	PopoverTrigger,
} from "@/components/ui/popover"
```

```tsx title="Anatomy"
<Popover>
	<PopoverTrigger />
	<PopoverPopup>
		<Calendar />
	</PopoverPopup>
</Popover>
```

## Examples

### Range

To select a range, set `mode="range"` on `Calendar`.

<ComponentPreview name="date-picker-range-demo" />

### Field

Place it inside [Field](/docs/components/field) and point `FieldLabel` at the trigger with `htmlFor`.

<ComponentPreview name="date-picker-field-demo" />

### Date of Birth

To jump between months and years, set `captionLayout="dropdown"` on `Calendar`.

<ComponentPreview name="date-picker-date-of-birth-demo" />

### Input

To let people type the date, use an `InputGroup` and pass its ref to `anchor` on `PopoverPopup`.

<ComponentPreview name="date-picker-input-demo" />

### Time Input

To pick a time too, add an input with `type="time"`.

<ComponentPreview name="date-picker-time-input-demo" />

### Natural Language

To accept text like "next Friday", parse the input with [`chrono-node`](https://github.com/wanasit/chrono).
