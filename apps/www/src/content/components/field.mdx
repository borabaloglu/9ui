## Usage

```tsx title="Imports"
import {
	Field,
	FieldControl,
	FieldDescription,
	FieldError,
	FieldItem,
	FieldLabel,
	FieldValidity,
} from "@/components/ui/field"
```

```tsx title="Anatomy"
<Field>
	<FieldLabel />
	<Input />
	<FieldDescription />
	<FieldError />
</Field>
```

The label, description and error are linked to the control for you. Don't set `id`, `htmlFor` or `aria-describedby` by hand.

### Description

### Error
