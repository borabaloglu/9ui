## Usage

```tsx title="Imports"
import {
	Field,
	FieldControl,
	FieldDescription,
	FieldError,
	FieldItem,
	FieldLabel,
	FieldValidity,
} from "@/components/ui/field"
```

```tsx title="Anatomy"
<Field>
	<FieldLabel />
	<Input />
	<FieldDescription />
	<FieldError />
</Field>
```

## Tips

<Tips>

<Tip title="Link the label, description and error">

Place the label, description and error inside `Field` to link them to the control. Don't set `id`, `htmlFor` or `aria-describedby` by hand.

```tsx {2,4-5}
<Field name="username">
	<FieldLabel>Username</FieldLabel>
	<Input required />
	<FieldDescription>Your public display name.</FieldDescription>
	<FieldError match="valueMissing">Enter a username.</FieldError>
</Field>
```

</Tip>

<Tip title="Label each option in a group">

Use `FieldItem` for each option in a checkbox or radio group.

```tsx {3,9}
<Field name="channels">
	<CheckboxGroup defaultValue={["email"]}>
		<FieldItem>
			<FieldLabel>
				<Checkbox value="email" />
				Email
			</FieldLabel>
		</FieldItem>
		<FieldItem>
			<FieldLabel>
				<Checkbox value="sms" />
				Text messages
			</FieldLabel>
		</FieldItem>
	</CheckboxGroup>
</Field>
```

</Tip>

<Tip title="Render your own input">

Use `FieldControl` to render your own input.

```tsx {3-6}
<Field name="email">
	<FieldLabel>Email</FieldLabel>
	<FieldControl
		type="email"
		className="h-9 rounded-md border px-3 text-sm"
	/>
</Field>
```

</Tip>

<Tip title="Read the validity state">

Use `FieldValidity` to read the validity state.

```tsx {4-6}
<Field name="email">
	<FieldLabel>Email</FieldLabel>
	<Input type="email" required />
	<FieldValidity>
		{(state) => state.validity.valueMissing && <p>Enter your email.</p>}
	</FieldValidity>
</Field>
```

</Tip>

</Tips>
