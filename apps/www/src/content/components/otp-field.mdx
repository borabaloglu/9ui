## Usage

```tsx title="Imports"

	OTPField,
	OTPFieldInput,
	OTPFieldSeparator,
} from "@/components/ui/otp-field"
```

```tsx title="Anatomy"
<OTPField>
	<OTPFieldInput />
	<OTPFieldSeparator />
</OTPField>
```

## Tips

<Tips>

<Tip title="Label the field">

Give every field a visible label: set `id` on `OTPField` and point a [Label](/docs/components/label) at it with `htmlFor`, or use [Field](/docs/components/field).

```tsx {1-2}
<Label htmlFor="code">Verification code</Label>
<OTPField id="code" length={6}>
	{Array.from({ length: 6 }, (_, index) => (
		<OTPFieldInput key={index} aria-label={`Character ${index + 1} of 6`} />
	))}
</OTPField>
```

</Tip>

<Tip title="Announce the position of each slot">

To announce the position of each slot, set `aria-label` on `OTPFieldInput`.

```tsx {3}
<OTPField length={6}>
	{Array.from({ length: 6 }, (_, index) => (
		<OTPFieldInput key={index} aria-label={`Character ${index + 1} of 6`} />
	))}
</OTPField>
```

</Tip>

<Tip title="Set the number of slots">

Set `length` on `OTPField` to the number of slots and render one `OTPFieldInput` for each.

```tsx {1}
<OTPField length={4}>
	<OTPFieldInput aria-label="Character 1 of 4" />
	<OTPFieldInput aria-label="Character 2 of 4" />
	<OTPFieldInput aria-label="Character 3 of 4" />
	<OTPFieldInput aria-label="Character 4 of 4" />
</OTPField>
```

</Tip>

</Tips>
