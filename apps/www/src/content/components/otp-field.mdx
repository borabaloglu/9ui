## Usage

```tsx title="Imports"
import {
	OTPField,
	OTPFieldInput,
	OTPFieldSeparator,
} from "@/components/ui/otp-field"
```

```tsx title="Anatomy"
<OTPField>
	<OTPFieldInput />
	<OTPFieldSeparator />
</OTPField>
```

Set `length` to the number of slots and render one `OTPFieldInput` for each. Give every field a visible label: pass an `id` and point a [Label](/docs/components/label) at it with `htmlFor`, or use [Field](/docs/components/field). The label names the first slot, so set `aria-label` on the others to announce their position.
