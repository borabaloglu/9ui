## Usage

```tsx title="Imports"
import {
	NumberField,
	NumberFieldDecrement,
	NumberFieldGroup,
	NumberFieldIncrement,
	NumberFieldInput,
	NumberFieldScrubArea,
} from "@/components/ui/number-field"
```

```tsx title="Anatomy"
<NumberField>
	<NumberFieldScrubArea />
	<NumberFieldGroup>
		<NumberFieldDecrement />
		<NumberFieldInput />
		<NumberFieldIncrement />
	</NumberFieldGroup>
</NumberField>
```

## Examples

### Size

Set `size="sm"`, `size="default"` or `size="lg"` on `NumberField`.

<ComponentPreview name="number-field-size-demo" />

### Step

Set `step` on `NumberField` to change how much each press adds or removes. Hold Shift for `largeStep` and Alt for `smallStep`.

<ComponentPreview name="number-field-step-demo" />

### Format

Set `format` on `NumberField` to show the value as a currency, percentage or unit. It takes the same options as `Intl.NumberFormat`.

<ComponentPreview name="number-field-format-demo" />

### Scrub

Wrap the label in `NumberFieldScrubArea` to change the value by dragging it.

<ComponentPreview name="number-field-scrub-demo" />

### Wheel Scrub

Set `allowWheelScrub` on `NumberField` to change the value with the mouse wheel while the input is focused and hovered.

<ComponentPreview name="number-field-wheel-scrub-demo" />

### Read-Only

Set `readOnly` on `NumberField` to show a value that can't be changed.

<ComponentPreview name="number-field-read-only-demo" />

### Disabled

Set `disabled` on `NumberField` to prevent interaction.

<ComponentPreview name="number-field-disabled-demo" />

### Invalid

Set `invalid` on `Field` to show the error state, and clear it once the value is valid.

## Tips

<Tips>

<Tip title="Label the number field">

To label a number field, wrap it in [Field](/docs/components/field) with a `FieldLabel`.

```tsx {1-2}
<Field name="quantity">
	<FieldLabel>Quantity</FieldLabel>
	<NumberField defaultValue={1}>
		<NumberFieldGroup>
			<NumberFieldDecrement />
			<NumberFieldInput />
			<NumberFieldIncrement />
		</NumberFieldGroup>
	</NumberField>
</Field>
```

</Tip>

<Tip title="Name a number field with no visible label">

Set `aria-label` on `NumberFieldInput` when there is no visible label.

```tsx {4}
<NumberField defaultValue={1}>
	<NumberFieldGroup>
		<NumberFieldDecrement />
		<NumberFieldInput aria-label="Quantity" />
		<NumberFieldIncrement />
	</NumberFieldGroup>
</NumberField>
```

</Tip>

</Tips>
