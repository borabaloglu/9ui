## Usage

```tsx title="Imports"
import {
	Pagination,
	PaginationContent,
	PaginationEllipsis,
	PaginationItem,
	PaginationLink,
	PaginationNext,
	PaginationPrevious,
} from "@/components/ui/pagination"
```

```tsx title="Anatomy"
<Pagination>
	<PaginationContent>
		<PaginationItem>
			<PaginationPrevious />
		</PaginationItem>
		<PaginationItem>
			<PaginationLink />
		</PaginationItem>
		<PaginationItem>
			<PaginationEllipsis />
		</PaginationItem>
		<PaginationItem>
			<PaginationNext />
		</PaginationItem>
	</PaginationContent>
</Pagination>
```

Set `active` on the `PaginationLink` of the current page.

## Examples

### Simple

To show page numbers only, leave out `PaginationPrevious` and `PaginationNext`.

<ComponentPreview name="pagination-simple-demo" />

### Icons Only

To hide the labels, set `text=""` and `size="icon"` on `PaginationPrevious` and `PaginationNext`.

<ComponentPreview name="pagination-icons-only-demo" />

### Size

To change the size, set `size` on `PaginationPrevious`, `PaginationNext`, `PaginationLink` and `PaginationEllipsis`.

<ComponentPreview name="pagination-size-demo" />

### Disabled

To disable `PaginationPrevious` or `PaginationNext`, set `aria-disabled` and leave out `href`.

<ComponentPreview name="pagination-disabled-demo" />

### Next.js Link

To use a framework link, pass it to the `render` prop.

<ComponentPreview name="pagination-next-link-demo" />

### RTL

To show the pagination right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="pagination-rtl-demo" direction="rtl" />
