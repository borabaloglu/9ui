## Examples

### Single Date

To select one date, set `mode="single"` on `Calendar`.

<ComponentPreview name="calendar-single-date-demo" />

### Multiple Dates

To select several dates, set `mode="multiple"` on `Calendar`.

<ComponentPreview name="calendar-multiple-dates-demo" />

### Date Range

To select a range, set `mode="range"` on `Calendar`. To show two months, set `numberOfMonths={2}`.

<ComponentPreview name="calendar-date-range-demo" />

### Month and Year Selector

To pick the month and year from dropdowns, set `captionLayout="dropdown"` on `Calendar`.

<ComponentPreview name="calendar-month-and-year-selector-demo" />

### Custom Month and Year Selector

To replace the dropdowns, pass your own `Dropdown` to `components`. This example uses `Select`.

<ComponentPreview name="calendar-custom-month-and-year-selector-demo" />

### Week Numbers

To show week numbers, set `showWeekNumber` on `Calendar`.

<ComponentPreview name="calendar-week-numbers-demo" />

### Disabled

To disable dates, pass them to `disabled`.

<ComponentPreview name="calendar-disabled-demo" />

### Presets

To jump to a date from outside the calendar, control `selected` and `month`.

<ComponentPreview name="calendar-presets-demo" />

### Custom Cell

To add content to a day, wrap `CalendarDayButton` and pass it as `DayButton` to `components`. To change the cell size, set `--cell-size`.

<ComponentPreview name="calendar-custom-cell-demo" />

To enable RTL support, see the [RTL guide](/docs/getting-started/rtl).

## Tips

<Tips>

<Tip title="Control the selection">

To control the selection, set `selected` and `onSelect`.

```tsx {5-6}
const [date, setDate] = useState<Date | undefined>(undefined)

<Calendar
	mode="single"
	selected={date}
	onSelect={setDate}
/>
```

</Tip>

</Tips>
