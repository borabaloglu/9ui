## Usage

```tsx title="Imports"
import {
	SegmentedControl,
	SegmentedControlItem,
	SegmentedControlLabel,
} from "@/components/ui/segmented-control"
```

```tsx title="Anatomy"
<SegmentedControlLabel />
<SegmentedControl>
	<SegmentedControlItem />
	<SegmentedControlItem />
</SegmentedControl>
```

Use Segmented Control when one option is always selected, such as a view or a unit. For options that can be turned off or combined, use [Toggle Group](/docs/components/toggle-group). To switch between panels of content, use [Tabs](/docs/components/tabs).

## Tips

<Tips>

<Tip title="Size segments to their labels">

Segments are equally wide. To make each one as wide as its label, set an `auto-cols-auto` class on `SegmentedControl`.

```tsx {1}
<SegmentedControl className="auto-cols-auto" defaultValue="all">
	<SegmentedControlItem value="all">All</SegmentedControlItem>
	<SegmentedControlItem value="archived">Archived</SegmentedControlItem>
</SegmentedControl>
```

</Tip>

<Tip title="Truncate long labels">

Segments shrink to fit a narrow container and cut off a label that doesn't fit. To end it with an ellipsis, wrap the label in an element with a `truncate` class.

```tsx {3}
<SegmentedControl defaultValue="notifications">
	<SegmentedControlItem value="notifications">
		<span className="truncate">Notifications</span>
	</SegmentedControlItem>
	<SegmentedControlItem value="appearance">
		<span className="truncate">Appearance</span>
	</SegmentedControlItem>
</SegmentedControl>
```

</Tip>

</Tips>
