## Usage

```tsx title="Imports"
import {
	Progress,
	ProgressCircularIndicator,
	ProgressCircularTrack,
	ProgressIndicator,
	ProgressLabel,
	ProgressTrack,
	ProgressValue,
} from "@/components/ui/progress"
```

```tsx title="Anatomy"
<Progress>
	<ProgressLabel />
	<ProgressValue />
	<ProgressTrack>
		<ProgressIndicator />
	</ProgressTrack>
</Progress>
```

## Examples

### Without Label

Leave out `ProgressLabel` and `ProgressValue` to show only the bar.

<ComponentPreview name="progress-without-label-demo" showReload={true} />

### Custom Value

To write the value text yourself, pass a function to `ProgressValue`. Set `getAriaValueText` so screen readers hear the same text.

<ComponentPreview name="progress-custom-value-demo" showReload={true} />

### Indeterminate

Set `value={null}` on `Progress` when the amount of progress is unknown.

<ComponentPreview name="progress-indeterminate-demo" />

### Circular

To show a ring instead of a bar, use `ProgressCircularTrack` and `ProgressCircularIndicator`, and set `className="flex items-center"` on `Progress`.

<ComponentPreview name="progress-circular-demo" showReload={true} />
