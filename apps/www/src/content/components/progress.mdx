## Usage

```tsx title="Imports"
import {
	Progress,
	ProgressIndicator,
	ProgressLabel,
	ProgressTrack,
	ProgressValue,
} from "@/components/ui/progress"
```

```tsx title="Anatomy"
<Progress>
	<ProgressLabel />
	<ProgressValue />
	<ProgressTrack>
		<ProgressIndicator />
	</ProgressTrack>
</Progress>
```

Give every progress bar a name: add a `ProgressLabel`, or set `aria-label` on `Progress` when there is no visible label.
