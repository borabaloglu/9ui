## Usage

```tsx title="Imports"
import {
	Progress,
	ProgressCircularIndicator,
	ProgressCircularTrack,
	ProgressIndicator,
	ProgressLabel,
	ProgressTrack,
	ProgressValue,
} from "@/components/ui/progress"
```

```tsx title="Anatomy"
<Progress>
	<ProgressLabel />
	<ProgressValue />
	<ProgressTrack>
		<ProgressIndicator />
	</ProgressTrack>
</Progress>
```

Give every progress bar a name: add a `ProgressLabel`, or set `aria-label` on `Progress` when there is no visible label.

## Examples

### Without Label

Leave out `ProgressLabel` and `ProgressValue` to show only the bar.

<ComponentPreview name="progress-without-label-demo" showReload={true} />

### Formatted Value

Pass a function to `ProgressValue` to show the value in your own format.

<ComponentPreview name="progress-formatted-value-demo" showReload={true} />

### Indeterminate

Set `value={null}` when the amount of progress is unknown.

<ComponentPreview name="progress-indeterminate-demo" />

### Circular

To show a ring instead of a bar, use `ProgressCircularTrack` and `ProgressCircularIndicator`. Set `size` and `strokeWidth` on `ProgressCircularTrack` to change its dimensions.

<ComponentPreview name="progress-circular-demo" showReload={true} />

### RTL

To show the progress right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="progress-rtl-demo" direction="rtl" />
