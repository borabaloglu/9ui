## Usage

```tsx title="Imports"
import { Slider, SliderLabel, SliderValue } from "@/components/ui/slider"
```

```tsx title="Anatomy"
<Slider>
	<SliderLabel />
	<SliderValue />
</Slider>
```

## Examples

### Range

Pass an array to `defaultValue` or `value` to get one thumb per value.

<ComponentPreview name="slider-range-demo" />

### Label and Value

Add `SliderLabel` to name the slider and `SliderValue` to show the current value.

<ComponentPreview name="slider-label-and-value-demo" />

### Step

Set `step` on `Slider` to snap the value to an increment, and `largeStep` for Page Up, Page Down and Shift with the arrow keys.

<ComponentPreview name="slider-step-demo" />

### Marks

Render marks as children and position each one as a percentage of the range. Inset the row by half the thumb so the marks line up with it.

<ComponentPreview name="slider-marks-demo" />

### Format

Set `format` on `Slider` to show the value as a currency, percentage or unit. It takes the same options as `Intl.NumberFormat`.

<ComponentPreview name="slider-format-demo" />

### Disabled

Set `disabled` on `Slider` to prevent interaction. The label and value dim with the slider.

<ComponentPreview name="slider-disabled-demo" />

### Invalid

Set `invalid` on `Field` to show the error state, and clear it once the value is valid.

<ComponentPreview name="slider-invalid-demo" showReload={true} />

### Field

Place it inside [Field](/docs/components/field) to add a description.

<ComponentPreview name="slider-field-demo" />

### Vertical

Set `orientation="vertical"` on `Slider` for a vertical slider.

<ComponentPreview name="slider-vertical-demo" />

## Tips

<Tips>

<Tip title="Name each thumb of a range slider">

On a range slider, set `thumbLabels` on `Slider` to name each thumb.

```tsx {3}
<Slider
	defaultValue={[20, 80]}
	thumbLabels={["Minimum price", "Maximum price"]}
/>
```

</Tip>

</Tips>
