## Usage

```tsx title="Imports"
import {
	Menubar,
	MenubarCheckboxItem,
	MenubarGroup,
	MenubarGroupLabel,
	MenubarItem,
	MenubarLinkItem,
	MenubarMenu,
	MenubarPopup,
	MenubarRadioGroup,
	MenubarRadioItem,
	MenubarSeparator,
	MenubarShortcut,
	MenubarSub,
	MenubarSubPopup,
	MenubarSubTrigger,
	MenubarTrigger,
} from "@/components/ui/menubar"
```

```tsx title="Anatomy"
<Menubar>
	<MenubarMenu>
		<MenubarTrigger />
		<MenubarPopup>
			<MenubarGroup>
				<MenubarGroupLabel />
				<MenubarItem>
					<MenubarShortcut />
				</MenubarItem>
				<MenubarLinkItem />
			</MenubarGroup>
			<MenubarSeparator />
			<MenubarCheckboxItem />
			<MenubarRadioGroup>
				<MenubarRadioItem />
			</MenubarRadioGroup>
			<MenubarSub>
				<MenubarSubTrigger />
				<MenubarSubPopup>
					<MenubarItem />
				</MenubarSubPopup>
			</MenubarSub>
		</MenubarPopup>
	</MenubarMenu>
</Menubar>
```

The parts inside `MenubarPopup` work like the ones in [Menu](/docs/components/menu).

### With Icons

Place an icon before the item text.

### Link

Use `MenubarLinkItem` for items that go to another page. It renders an `<a>`.

<ComponentPreview name="menubar-link-demo" />

### Disabled

To disable one menu, set `disabled` on its `MenubarTrigger`. To disable the whole bar, set `disabled` on `Menubar`.

<ComponentPreview name="menubar-disabled-demo" />

### Vertical

To stack the triggers, set `orientation="vertical"` on `Menubar`.

<ComponentPreview name="menubar-vertical-demo" />

### RTL

To show the menubar right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).
