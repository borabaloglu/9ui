## Usage

```tsx title="Imports"
import { Switch } from "@/components/ui/switch"
```

```tsx title="Anatomy"
<Switch />
```

Give every switch a visible label. Place it inside [Label](/docs/components/label), or use [Field](/docs/components/field) when it also needs a description or an error message. For a sibling `label` with `htmlFor` outside a `Field`, render the switch as a button with `nativeButton` and `render={<button />}`.

### Sizes

### Invalid
