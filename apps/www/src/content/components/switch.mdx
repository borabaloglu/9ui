## Examples

### Size

Set `size="sm"` for a smaller switch.

<ComponentPreview name="switch-size-demo" />

### Disabled

Set `disabled` to prevent interaction. A `Label` around the switch dims with it.

<ComponentPreview name="switch-disabled-demo" />

### Invalid

Set `invalid` on `Field` to show the error state, and clear it once the switch is on. Outside a `Field`, set `aria-invalid` on the switch.

<ComponentPreview name="switch-invalid-demo" />

### Field

Place it inside [Field](/docs/components/field) to add a label and a description.

<ComponentPreview name="switch-field-demo" />

### Choice Card

## Tips

<Tips>

<Tip title="Use a sibling label">

To use a sibling `label` with `htmlFor` outside a `Field`, set `nativeButton` and `render={<button />}` on `Switch`.

```tsx {1}
<Switch id="notifications" nativeButton render={<button />} />
<Label htmlFor="notifications">Enable notifications</Label>
```

</Tip>

</Tips>
