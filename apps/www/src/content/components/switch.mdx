## Usage

```tsx title="Imports"
import { Switch } from "@/components/ui/switch"
```

```tsx title="Anatomy"
<Switch />
```

Give every switch a visible label. Place it inside [Label](/docs/components/label), or use [Field](/docs/components/field) when it also needs a description or an error message. For a sibling `label` with `htmlFor` outside a `Field`, render the switch as a button with `nativeButton` and `render={<button />}`.

## Examples

### Sizes

Set `size="sm"` for a smaller switch.

<ComponentPreview name="switch-sm-demo" />

### Disabled

Set `disabled` to prevent interaction. A `Label` around the switch dims with it.

<ComponentPreview name="switch-disabled-demo" />

### Invalid

Set `invalid` on `Field` to show the error state, and clear it once the switch is on. Outside a `Field`, set `aria-invalid` on the switch.

<ComponentPreview name="switch-invalid-demo" />

### Choice Card

Wrap the switch and its text in `FieldLabel` to make the whole card clickable. Style the checked card with `data-filled`.

<ComponentPreview name="switch-choice-card-demo" />

### RTL

To show the switch right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="switch-rtl-demo" direction="rtl" />
