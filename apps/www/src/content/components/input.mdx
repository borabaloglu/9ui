## Usage

```tsx title="Imports"
import { Input } from "@/components/ui/input"
```

```tsx title="Anatomy"
<Input />
```

Give every input a `<label>` or `aria-label`. A placeholder isn't a label.

## Examples

### Disabled

Set `disabled` to prevent interaction.

<ComponentPreview name="input-disabled-demo" />

### Read-only

Set `readOnly` to show a value that cannot be changed. The field drops its fill and shadow. In a theme with a transparent `--input`, it looks the same as an editable field.

<ComponentPreview name="input-read-only-demo" />

### Invalid

Set `aria-invalid` to show the error state.

<ComponentPreview name="input-invalid-demo" />

### File

Set `type="file"` to accept files.

<ComponentPreview name="input-file-demo" />

### Input Group

Use [`Input Group`](/docs/components/input-group) to add icons, text, or buttons.

<ComponentPreview name="input-with-group-demo" />

### RTL

To show the input right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="input-rtl-demo" direction="rtl" />
