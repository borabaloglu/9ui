## Usage

```tsx title="Imports"
import {
	Select,
	SelectGroup,
	SelectGroupLabel,
	SelectItem,
	SelectLabel,
	SelectPopup,
	SelectSeparator,
	SelectTrigger,
	SelectValue,
} from "@/components/ui/select"
```

```tsx title="Anatomy"
<Select>
	<SelectLabel />
	<SelectTrigger>
		<SelectValue />
	</SelectTrigger>
	<SelectPopup>
		<SelectGroup>
			<SelectGroupLabel />
			<SelectItem />
		</SelectGroup>
		<SelectSeparator />
		<SelectItem />
	</SelectPopup>
</Select>
```

For long lists that need filtering, use [Combobox](/docs/components/combobox).

## Tips

<Tips>

<Tip title="Name the select">

Give every select a name: add a `SelectLabel`, use [Field](/docs/components/field) with a `FieldLabel` or set `aria-label` on `SelectTrigger`.

```tsx {2}
<Select items={items}>
	<SelectLabel>Fruit</SelectLabel>
	<SelectTrigger>
		<SelectValue />
	</SelectTrigger>
</Select>
```

</Tip>

<Tip title="Show the label of the selected value">

To show the label of the selected value instead of the raw value, pass `items` to `Select`.

```tsx {6}
const items = [
	{ label: "Apple", value: "apple" },
	{ label: "Banana", value: "banana" },
]

<Select items={items}>
	<SelectTrigger aria-label="Fruit">
		<SelectValue />
	</SelectTrigger>
</Select>
```

</Tip>

</Tips>
