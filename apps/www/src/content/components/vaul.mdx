## About

Vaul is built on top of [`vaul-base`](https://vaul-base.vercel.app), a port of [`vaul`](https://vaul.emilkowal.ski) to Base UI. `vaul` was originally created by [@emilkowalski\_](https://x.com/emilkowalski_).

For a drawer built on Base UI alone, see [Drawer](/docs/components/drawer).

## Usage

```tsx title="Imports"
import {
	Vaul,
	VaulClose,
	VaulContent,
	VaulDescription,
	VaulFooter,
	VaulHandle,
	VaulHeader,
	VaulNested,
	VaulOverlay,
	VaulPanel,
	VaulTitle,
	VaulTrigger,
} from "@/components/ui/vaul"
```

```tsx title="Anatomy"
<Vaul>
	<VaulTrigger />
	<VaulContent>
		<VaulHeader>
			<VaulTitle />
			<VaulDescription />
		</VaulHeader>
		<VaulPanel />
		<VaulFooter>
			<VaulClose />
		</VaulFooter>
	</VaulContent>
</Vaul>
```

On top and bottom drawers the header, panel and footer keep their content in a centered column, so it stays readable on wide screens.

## Examples

### Direction

Set `direction` on `Vaul` to choose the edge the drawer slides in from.

<ComponentPreview name="vaul-direction-demo" />

### Inset

Set `variant="inset"` on `VaulContent` to float the drawer inside the viewport with rounded corners on every side. Inset drawers aren't meant to be combined with snap points.

<ComponentPreview name="vaul-inset-demo" />

### Scrollable Content

Put long content in `VaulPanel`. To cap the height, set a `max-h-*` class on `VaulContent`.

<ComponentPreview name="vaul-scrollable-content-demo" />

### Snap Points

Set `snapPoints` on `Vaul` to let the drawer rest at fixed heights. Use pixel strings or a fraction of the screen height, and control the current one with `activeSnapPoint` and `setActiveSnapPoint`. The overlay stays half visible at the lower snap points and fades in fully at the last one.

<ComponentPreview name="vaul-snap-points-demo" />

### Nested

Use `VaulNested` as the root of a drawer opened from inside another. The parent scales down behind the nested one.

<ComponentPreview name="vaul-nested-demo" />

### Bare Footer

Set `variant="bare"` on `VaulFooter` to drop its border and background.

<ComponentPreview name="vaul-bare-footer-demo" />

### Scale Background

Set `shouldScaleBackground` on `Vaul` to scale the page down while the drawer is open. Add `data-vaul-drawer-wrapper` to the element that wraps your app.

```tsx
<div data-vaul-drawer-wrapper="">{children}</div>
```

The example below runs in a sandbox: the drawer is rendered into the frame with `container`, and the frame is the scaled wrapper. In your app the wrapper is the page itself.

## Tips

<Tips>

<Tip title="Label icon-only triggers">

Give icon-only triggers an `aria-label`.

```tsx {2}
<VaulTrigger
	render={<Button variant="outline" size="icon" aria-label="Settings" />}
>
	<SettingsIcon />
</VaulTrigger>
```

</Tip>

<Tip title="Use your own button as the trigger">

Set `render` on `VaulTrigger` to use your own button.

```tsx {1}
<VaulTrigger render={<Button variant="outline" />}>
	Send feedback
</VaulTrigger>
```

</Tip>

<Tip title="Scroll the body">

Put the body in `VaulPanel`. It scrolls when the content is taller than the drawer, while the header and footer stay in place.

```tsx {5-7}
<VaulContent>
	<VaulHeader>
		<VaulTitle>Terms of service</VaulTitle>
	</VaulHeader>
	<VaulPanel>
		<p>By using this service you agree to these terms.</p>
	</VaulPanel>
	<VaulFooter>
		<VaulClose render={<Button />}>Accept</VaulClose>
	</VaulFooter>
</VaulContent>
```

</Tip>

<Tip title="Clear the status bar and home indicator">

To keep content clear of the status bar and home indicator, set `viewport-fit=cover` in the viewport meta tag of the page.

```tsx {3}
<meta
	name="viewport"
	content="width=device-width, initial-scale=1, viewport-fit=cover"
/>
```

</Tip>

<Tip title="Change the corner radius">

To change the corner radius, set `className="[--vaul-radius:var(--radius-xl)]"` on `VaulContent`.

```tsx {1}
<VaulContent className="[--vaul-radius:var(--radius-xl)]">
	<VaulTitle>Send feedback</VaulTitle>
</VaulContent>
```

</Tip>

<Tip title="Hide or move the handle">

The handle shows on top and bottom drawers. To remove it, set `showHandle={false}` on `VaulContent`, and render `VaulHandle` yourself to place it elsewhere. To make the handle the only area that drags, set `handleOnly` on `Vaul`.

```tsx {1,2}
<VaulContent showHandle={false}>
	<VaulHandle />
	<VaulPanel>Content</VaulPanel>
</VaulContent>
```

</Tip>

</Tips>
