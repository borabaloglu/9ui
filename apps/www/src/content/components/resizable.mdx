## Usage

```tsx title="Imports"
import {
	ResizableHandle,
	ResizablePanel,
	ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx title="Anatomy"
<ResizablePanelGroup>
	<ResizablePanel />
	<ResizableHandle />
	<ResizablePanel />
</ResizablePanelGroup>
```

To set the starting size of a panel, set `defaultSize` on `ResizablePanel`.

To limit how far a panel can be resized, set `minSize` and `maxSize` on `ResizablePanel`.
