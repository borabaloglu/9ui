## Usage

```tsx title="Imports"
import {
	ResizableHandle,
	ResizablePanel,
	ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx title="Anatomy"
<ResizablePanelGroup>
	<ResizablePanel />
	<ResizableHandle />
	<ResizablePanel />
</ResizablePanelGroup>
```

To set the starting size of a panel, set `defaultSize` on `ResizablePanel`.

To limit how far a panel can be resized, set `minSize` and `maxSize` on `ResizablePanel`.

### RTL

To show the resizable right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

In right to left, the handle's `aria-valuenow` and `aria-controls` describe the panel after the handle. This comes from react-resizable-panels.
