## Usage

```tsx title="Imports"
import {
	ResizableHandle,
	ResizablePanel,
	ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx title="Anatomy"
<ResizablePanelGroup>
	<ResizablePanel />
	<ResizableHandle />
	<ResizablePanel />
</ResizablePanelGroup>
```

## Tips

<Tips>

<Tip title="Limit how far a panel resizes">

To limit how far a panel can be resized, set `minSize` and `maxSize` on `ResizablePanel`.

```tsx {2}
<ResizablePanelGroup>
	<ResizablePanel minSize="20%" maxSize="40%">Sidebar</ResizablePanel>
	<ResizableHandle />
	<ResizablePanel>Content</ResizablePanel>
</ResizablePanelGroup>
```

</Tip>

</Tips>
