## Usage

```tsx title="Imports"
import {
	Tooltip,
	TooltipPopup,
	TooltipProvider,
	TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx title="Anatomy"
<TooltipProvider>
	<Tooltip>
		<TooltipTrigger />
		<TooltipPopup />
	</Tooltip>
</TooltipProvider>
```

Tooltips don't open on touch devices. Use a [Popover](/docs/components/popover) for content people need to read.

### Grouped

Wrap related tooltips in `TooltipProvider`. After the first one opens, the others open without a delay.

<ComponentPreview name="tooltip-grouped-demo" />

### Delay

Tooltips inside a `TooltipProvider` open after 300ms. Without one they open after 600ms. Set `delay` on `TooltipProvider` to change it for a group, or on `TooltipTrigger` for a single tooltip.

## Tips

<Tips>

<Tip title="Label icon-only triggers">

A tooltip is a visual hint only, so give icon-only triggers an `aria-label` that matches its text.

```tsx {3}
<Tooltip>
	<TooltipTrigger
		render={<Button variant="outline" size="icon" aria-label="Copy link" />}
	>
		<CopyIcon />
	</TooltipTrigger>
	<TooltipPopup>Copy link</TooltipPopup>
</Tooltip>
```

</Tip>

<Tip title="Use your own button as the trigger">

Set `render` on `TooltipTrigger` to use your own button.

```tsx {1}
<TooltipTrigger render={<Button variant="outline" />}>
	Share
</TooltipTrigger>
```

</Tip>

<Tip title="Change where the tooltip opens">

`TooltipPopup` takes `side`, `align`, `sideOffset` and `alignOffset` to change where the tooltip opens.

```tsx {1}
<TooltipPopup side="bottom" align="start" sideOffset={8}>
	Copy link
</TooltipPopup>
```

</Tip>

</Tips>
