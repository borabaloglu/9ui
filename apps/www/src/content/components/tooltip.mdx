## Usage

```tsx title="Imports"
import {
	Tooltip,
	TooltipPopup,
	TooltipProvider,
	TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx title="Anatomy"
<TooltipProvider>
	<Tooltip>
		<TooltipTrigger />
		<TooltipPopup />
	</Tooltip>
</TooltipProvider>
```

Set `render` on `TooltipTrigger` to use your own button. A tooltip is a visual hint only, so give icon-only triggers an `aria-label` that matches its text.

Tooltips don't open on touch devices. Use a [Popover](/docs/components/popover) for content people need to read.

`TooltipPopup` takes `side`, `align`, `sideOffset` and `alignOffset` to change where the tooltip opens.

### Delay

Tooltips inside a `TooltipProvider` open after 300ms. Without one they open after 600ms. Set `delay` on `TooltipProvider` to change it for a group, or on `TooltipTrigger` for a single tooltip.
