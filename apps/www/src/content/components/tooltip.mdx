## Usage

```tsx title="Imports"
import {
	Tooltip,
	TooltipPopup,
	TooltipProvider,
	TooltipTrigger,
} from "@/components/ui/tooltip"
```

```tsx title="Anatomy"
<TooltipProvider>
	<Tooltip>
		<TooltipTrigger />
		<TooltipPopup />
	</Tooltip>
</TooltipProvider>
```

Set `render` on `TooltipTrigger` to use your own button. A tooltip is a visual hint only, so give icon-only triggers an `aria-label` that matches its text.

Tooltips don't open on touch devices. Use a [Popover](/docs/components/popover) for content people need to read.

`TooltipPopup` takes `side`, `align`, `sideOffset` and `alignOffset` to change where the tooltip opens.

## Examples

### Side

Set `side` on `TooltipPopup` to choose where the tooltip opens.

<ComponentPreview name="tooltip-side-demo" />

### With Arrow

Set `showArrow` on `TooltipPopup` to point at the trigger. The tooltip moves away to make room for it.

<ComponentPreview name="tooltip-with-arrow-demo" />

### Grouped

Wrap related tooltips in `TooltipProvider`. After the first one opens, the others open without a delay.

<ComponentPreview name="tooltip-grouped-demo" />

### Delay

Tooltips inside a `TooltipProvider` open after 300ms. Without one they open after 600ms. Set `delay` on `TooltipProvider` to change it for a group, or on `TooltipTrigger` for a single tooltip.

<ComponentPreview name="tooltip-delay-demo" />

### RTL

To show the tooltip right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).
