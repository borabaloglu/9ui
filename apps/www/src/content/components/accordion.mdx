## Usage

```tsx title="Imports"
import {
	Accordion,
	AccordionItem,
	AccordionPanel,
	AccordionTrigger,
} from "@/components/ui/accordion"
```

```tsx title="Anatomy"
<Accordion>
	<AccordionItem>
		<AccordionTrigger />
		<AccordionPanel />
	</AccordionItem>
</Accordion>
```

## Tips

<Tips>

<Tip title="Let find in page open closed panels">

To let the browser's find in page open closed panels, set `hiddenUntilFound` on `Accordion`.

```tsx {1}
<Accordion hiddenUntilFound>
	<AccordionItem>
		<AccordionTrigger>Shipping</AccordionTrigger>
		<AccordionPanel>Orders ship within two days.</AccordionPanel>
	</AccordionItem>
</Accordion>
```

</Tip>

</Tips>
