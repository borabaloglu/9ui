## Usage

```tsx title="Imports"
import {
	Accordion,
	AccordionItem,
	AccordionPanel,
	AccordionTrigger,
} from "@/components/ui/accordion"
```

```tsx title="Anatomy"
<Accordion>
	<AccordionItem>
		<AccordionTrigger />
		<AccordionPanel />
	</AccordionItem>
</Accordion>
```

To open a panel by default, set `defaultValue` on `Accordion` to the `value` of its `AccordionItem`.

To let the browser's find in page open closed panels, set `hiddenUntilFound` on `Accordion`.
