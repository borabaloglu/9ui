## Usage

```tsx title="Imports"
import {
	Avatar,
	AvatarBadge,
	AvatarFallback,
	AvatarGroup,
	AvatarGroupOverflow,
	AvatarImage,
} from "@/components/ui/avatar"
```

```tsx title="Anatomy"
<AvatarGroup>
	<Avatar>
		<AvatarImage />
		<AvatarFallback />
		<AvatarBadge />
	</Avatar>
	<AvatarGroupOverflow />
</AvatarGroup>
```

## Tips

<Tips>

<Tip title="Use next/image">

To use `next/image`, set `keepMounted` on `AvatarImage` and pass the image to `render`.

```tsx {5-6}
import Image from "next/image"

<Avatar>
	<AvatarImage
		keepMounted
		render={<Image src="/avatars/maya.jpg" alt="Maya Chen" width={32} height={32} />}
	/>
	<AvatarFallback>MC</AvatarFallback>
</Avatar>
```

</Tip>

</Tips>

### AvatarBadge

A status dot at the bottom end corner. It sizes itself to the avatar.

### AvatarGroup

Overlaps its avatars with a cutout around each one.

### AvatarGroupOverflow

A count of the hidden avatars, sized to match the avatars in the group.
