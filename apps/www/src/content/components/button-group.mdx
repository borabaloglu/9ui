## Usage

```tsx title="Imports"
import {
	ButtonGroup,
	ButtonGroupSeparator,
	ButtonGroupText,
} from "@/components/ui/button-group"
```

```tsx title="Anatomy"
<ButtonGroup>
	<Button />
	<ButtonGroupSeparator />
	<Button />
	<ButtonGroupText />
</ButtonGroup>
```

For buttons that stay pressed, use [Toggle Group](/docs/components/toggle-group) instead.

## Tips

<Tips>

<Tip title="Label the group">

Give the group an `aria-label` when its purpose isn't clear from the buttons alone.

```tsx {1}
<ButtonGroup aria-label="Text alignment">
	<Button variant="outline">Left</Button>
	<Button variant="outline">Center</Button>
	<Button variant="outline">Right</Button>
</ButtonGroup>
```

</Tip>

</Tips>

## API Reference

Button Group is built by 9ui, so this is its full API.

### ButtonGroup

<ApiTable
	rows={[
		{
			name: "orientation",

			description: "Lays the items out in a row or a column.",
		},
	]}
/>

### ButtonGroupText

A text or icon segment that matches the buttons. To render it as another element, such as a label, set `render`.

### ButtonGroupSeparator

A line between items. It follows the orientation of the group, so it takes no `orientation` prop.
