## Usage

```tsx title="Imports"
import {
	Collapsible,
	CollapsiblePanel,
	CollapsibleTrigger,
} from "@/components/ui/collapsible"
```

```tsx title="Anatomy"
<Collapsible>
	<CollapsibleTrigger />
	<CollapsiblePanel />
</Collapsible>
```

## Tips

<Tips>

<Tip title="Open the panel by default">

To open the panel by default, set `defaultOpen` on `Collapsible`.

```tsx {1}
<Collapsible defaultOpen>
	<CollapsibleTrigger>Order details</CollapsibleTrigger>
	<CollapsiblePanel>Orders ship within two days.</CollapsiblePanel>
</Collapsible>
```

</Tip>

<Tip title="Let find in page open a closed panel">

To let the browser's find in page open a closed panel, set `hiddenUntilFound` on `CollapsiblePanel`.

```tsx {3}
<Collapsible>
	<CollapsibleTrigger>Order details</CollapsibleTrigger>
	<CollapsiblePanel hiddenUntilFound>
		Orders ship within two days.
	</CollapsiblePanel>
</Collapsible>
```

</Tip>

</Tips>
