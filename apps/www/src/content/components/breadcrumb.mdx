## Usage

```tsx title="Imports"
import {
	Breadcrumb,
	BreadcrumbEllipsis,
	BreadcrumbItem,
	BreadcrumbLink,
	BreadcrumbList,
	BreadcrumbPage,
	BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"
```

```tsx title="Anatomy"
<Breadcrumb>
	<BreadcrumbList>
		<BreadcrumbItem>
			<BreadcrumbLink />
		</BreadcrumbItem>
		<BreadcrumbSeparator />
		<BreadcrumbItem>
			<BreadcrumbEllipsis />
		</BreadcrumbItem>
		<BreadcrumbSeparator />
		<BreadcrumbItem>
			<BreadcrumbPage />
		</BreadcrumbItem>
	</BreadcrumbList>
</Breadcrumb>
```

### Custom Separator

To change the separator, pass an icon or text to `BreadcrumbSeparator` as children.

### Collapsed

To shorten a long path, put the middle pages in a [Menu](/docs/components/menu) and put `BreadcrumbEllipsis` inside its trigger. Give the trigger an `aria-label`.

## API Reference

Breadcrumb is built by 9ui, so this is its full API. Each part takes the props of its HTML element and adds none of its own.

### BreadcrumbLink

To use your router's link, set `render`.

### BreadcrumbPage

The current page. It isn't a link and is marked with `aria-current="page"`.

### BreadcrumbSeparator

Shows a chevron. To use another separator, pass it as children.
