## Usage

```tsx title="Imports"
import {
	EmojiPicker,
	EmojiPickerContent,
	EmojiPickerEmpty,
	EmojiPickerFooter,
	EmojiPickerList,
	EmojiPickerLoading,
	EmojiPickerPreview,
	EmojiPickerSearch,
	EmojiPickerSkinToneSelector,
} from "@/components/ui/emoji-picker"
```

```tsx title="Anatomy"
<EmojiPicker>
	<EmojiPickerSearch />
	<EmojiPickerContent>
		<EmojiPickerLoading />
		<EmojiPickerEmpty />
		<EmojiPickerList />
	</EmojiPickerContent>
	<EmojiPickerFooter>
		<EmojiPickerPreview />
		<EmojiPickerSkinToneSelector />
	</EmojiPickerFooter>
</EmojiPicker>
```

## Examples

### Popover

To show the picker in a popover, set `className="w-auto p-0"` on `PopoverPopup`.

### Skin Tone

To let people change the skin tone, add `EmojiPickerSkinToneSelector` to `EmojiPickerFooter`.

To add emojis to a text input, use an `InputGroup` and pass its ref to `anchor` on `PopoverPopup`.

## Tips

<Tips>

<Tip title="Get the picked emoji">

To get the picked emoji, set `onEmojiSelect` on `EmojiPicker`.

```tsx {1}
<EmojiPicker onEmojiSelect={({ emoji }) => setReaction(emoji)}>
	<EmojiPickerSearch />
	<EmojiPickerContent>
		<EmojiPickerList />
	</EmojiPickerContent>
</EmojiPicker>
```

</Tip>

</Tips>

## API Reference

What 9ui adds to Frimousse. See the [Frimousse](https://frimousse.liveblocks.io/#api-reference) documentation for the rest.

### EmojiPickerSearch

Renders the search field inside an [Input Group](/docs/components/input-group) with a search icon.

<ApiTable
	rows={[
		{
			name: "aria-label",
			type: "string",
			default: '"Search emoji"',
			description: "The accessible name of the search field.",
		},
	]}
/>

### EmojiPickerContent

Wraps `EmojiPicker.Viewport`.

### EmojiPickerLoading

Shows a spinner unless you pass children.

### EmojiPickerEmpty

Shows "No emoji found." unless you pass children.

### EmojiPickerList

<ApiTable
	rows={[
		{
			name: "components",
			type: "Partial<EmojiPickerListComponents>",
			description: <>Replaces the 9ui <code>CategoryHeader</code>, <code>Row</code> or <code>Emoji</code> component. Parts you leave out keep the 9ui styles.</>,
		},
	]}
/>

### EmojiPickerFooter

A row at the bottom of the picker for the preview and skin tone selector.

### EmojiPickerPreview

Shows the highlighted emoji and its name. Shows "Select an emoji…" when none is highlighted, unless you pass children.
