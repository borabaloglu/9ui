## Usage

```tsx title="Imports"
import { Textarea } from "@/components/ui/textarea"
```

```tsx title="Anatomy"
<Textarea />
```

Give every textarea a `<label>` or `aria-label`. A placeholder isn't a label.

## Examples

### Disabled

Set `disabled` to prevent interaction.

<ComponentPreview name="textarea-disabled-demo" />

### Read-only

Set `readOnly` to show a value that cannot be changed. The field drops its fill and shadow. In a theme with a transparent `--input`, it looks the same as an editable field.

<ComponentPreview name="textarea-read-only-demo" />

### Invalid

Set `aria-invalid` to show the error state.

<ComponentPreview name="textarea-invalid-demo" />

### Max height

Set a `max-h-*` class to stop growing and scroll instead.

<ComponentPreview name="textarea-max-height-demo" />

### Field

Place it inside [`Field`](/docs/components/field) to link the label, description and error. No `FieldControl` needed.

<ComponentPreview name="textarea-field-demo" />

### Input Group

Use [`Input Group`](/docs/components/input-group) to add a header, footer, or buttons.

<ComponentPreview name="textarea-with-group-demo" />

### RTL

To show the textarea right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).

<ComponentPreview name="textarea-rtl-demo" direction="rtl" />
