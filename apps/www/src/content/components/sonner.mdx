## Usage

```tsx title="Imports"
import { toast } from "sonner"
```

```tsx title="Toast"
toast("Event added to calendar", {
	description: "Wednesday, April 23 at 4:20 PM",
})
```

<ComponentPreview name="sonner-close-button-demo" />
