## Usage

```tsx title="Imports"
import { PhoneInput } from "@/components/ui/phone-input"
```

```tsx title="Anatomy"
<PhoneInput />
```

`value` and `onChange` use the E.164 format, for example `+905321234567`. Give every phone input a name: use [Field](/docs/components/field) with a `FieldLabel`, or set `aria-label`.

## Examples

### Default Country

Set `defaultCountry` to select a country before the user types.

<ComponentPreview name="phone-input-default-country-demo" />

### Countries

Set `countries` to limit the list to the countries you support.

<ComponentPreview name="phone-input-countries-demo" />

### Labels

Set `labels` to translate the country names. To translate the search field and the empty message, set `searchPlaceholder` and `emptyMessage`.

<ComponentPreview name="phone-input-labels-demo" />

### International Format

Set `international` to always show the number with its calling code.

<ComponentPreview name="phone-input-international-demo" />

### National Format

Set `international={false}` to show the number without its calling code.

<ComponentPreview name="phone-input-national-demo" />

### Initial Value Format

Set `initialValueFormat="national"` to show an initial `value` in the national format.

<ComponentPreview name="phone-input-initial-value-format-demo" />

### Formatting Value

Use `formatPhoneNumber` and `formatPhoneNumberIntl` to display a stored value.

<ComponentPreview name="phone-input-formatting-value-demo" />

### Disabled

Set `disabled` on `PhoneInput` to prevent interaction. `disabled` on `Field` does not reach the country button.

<ComponentPreview name="phone-input-disabled-demo" />

### Invalid

Set `invalid` on `Field` to show the error state. Outside a `Field`, set `aria-invalid`.

<ComponentPreview name="phone-input-invalid-demo" showReload={true} />

### Form

Use `isValidPhoneNumber` to check the value when the form is submitted.
