## Tips

<Tips>

<Tip title="Label the phone input">

To label a phone input, use [Field](/docs/components/field) with a `FieldLabel`.

```tsx {1-2}
<Field name="phoneNumber">
	<FieldLabel>Phone number</FieldLabel>
	<PhoneInput value={phoneNumber} onChange={setPhoneNumber} />
</Field>
```

</Tip>

<Tip title="Name a phone input with no visible label">

Set `aria-label` on `PhoneInput` when there is no visible label.

```tsx {2}
<PhoneInput
	aria-label="Phone number"
	value={phoneNumber}
	onChange={setPhoneNumber}
/>
```

</Tip>

<Tip title="Read and set the value">

`value` and `onChange` use the E.164 format, for example `+905321234567`.

```tsx {1,5-6}
const [phoneNumber, setPhoneNumber] = useState("+905321234567")

<PhoneInput
	aria-label="Phone number"
	value={phoneNumber}
	onChange={setPhoneNumber}
/>
```

</Tip>

</Tips>
