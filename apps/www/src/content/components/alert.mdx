	Alert,
	AlertAction,
	AlertDescription,
	AlertTitle,

```tsx title="Anatomy"

```

## Tips

<Tips>

<Tip title="Announce a message that isn't urgent">

For a message that isn't urgent, set `role="status"` on `Alert`.

```tsx {1}
<Alert role="status">
	<AlertTitle>Changes saved</AlertTitle>
	<AlertDescription>Your profile is up to date.</AlertDescription>
</Alert>
```

</Tip>

<Tip title="Show an icon">

To show an icon, put it first inside `Alert`.

```tsx {2}
<Alert>
	<InfoIcon />
	<AlertTitle>View-only access</AlertTitle>
	<AlertDescription>Ask an owner for permission to make edits.</AlertDescription>
</Alert>
```

</Tip>

<Tip title="Make the title a heading">

To make the title a heading, set `render` on `AlertTitle`.

```tsx {1}
<AlertTitle render={<h3 />}>View-only access</AlertTitle>
```

</Tip>

</Tips>
