## Usage

```tsx title="Imports"
import {
	Alert,
	AlertAction,
	AlertDescription,
	AlertTitle,
} from "@/components/ui/alert"
```

```tsx title="Anatomy"
<Alert>
	<AlertTitle />
	<AlertDescription />
	<AlertAction />
</Alert>
```

To show an icon, put it first inside `Alert`.

For a message that isn't urgent, set `role="status"` on `Alert`.

### Heading

To make the title a heading, set `render` on `AlertTitle`.

```tsx
<AlertTitle render={<h3 />}>View-only access</AlertTitle>
```

### RTL

To show the alert right to left, set `dir="rtl"` on `html` and wrap your app in `DirectionProvider`. See [RTL](/docs/getting-started/rtl).
