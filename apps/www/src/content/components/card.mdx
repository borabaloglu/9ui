## Usage

```tsx title="Imports"
import {
	Card,
	CardAction,
	CardContent,
	CardDescription,
	CardFooter,
	CardHeader,
	CardTitle,
} from "@/components/ui/card"
```

```tsx title="Anatomy"
<Card>
	<CardHeader>
		<CardTitle />
		<CardDescription />
		<CardAction />
	</CardHeader>
	<CardContent />
	<CardFooter />
</Card>
```

`CardTitle` renders a `div`. Pass `render` to make it a heading that fits your page outline.

```tsx
<CardTitle render={<h2 />}>Create project</CardTitle>
```
