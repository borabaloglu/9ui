## Usage

```tsx title="Imports"
import { Checkbox } from "@/components/ui/checkbox"
import {
	CheckboxGroup,
	CheckboxGroupLabel,
} from "@/components/ui/checkbox-group"
```

```tsx title="Anatomy"
<CheckboxGroup>
	<CheckboxGroupLabel />
	<Checkbox />
</CheckboxGroup>
```

## Tips

<Tips>

<Tip title="Name the group">

To name the group, set an `id` on `CheckboxGroupLabel` and pass it to `aria-labelledby` on `CheckboxGroup`.

```tsx {1-2}
<CheckboxGroup aria-labelledby="notify-label">
	<CheckboxGroupLabel id="notify-label">Notify me by</CheckboxGroupLabel>
	<Label>
		<Checkbox value="email" />
		Email
	</Label>
</CheckboxGroup>
```

</Tip>

<Tip title="Give each checkbox a value">

Give each [Checkbox](/docs/components/checkbox) a `value`. The group's value is the list of checked values.

```tsx {1,3,7}
<CheckboxGroup defaultValue={["email"]}>
	<Label>
		<Checkbox value="email" />
		Email
	</Label>
	<Label>
		<Checkbox value="sms" />
		Text messages
	</Label>
</CheckboxGroup>
```

</Tip>

</Tips>
