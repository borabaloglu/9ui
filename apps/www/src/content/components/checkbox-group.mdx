## Usage

```tsx title="Imports"
import { Checkbox } from "@/components/ui/checkbox"
import {
	CheckboxGroup,
	CheckboxGroupLabel,
} from "@/components/ui/checkbox-group"
```

```tsx title="Anatomy"
<CheckboxGroup>
	<CheckboxGroupLabel />
	<Checkbox />
</CheckboxGroup>
```

Give each [Checkbox](/docs/components/checkbox) a `value`. The group's value is the list of checked values. Name the group by giving `CheckboxGroupLabel` an `id` and passing it to `aria-labelledby`.
