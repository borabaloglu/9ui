## Usage

```tsx title="Imports"
import { Label } from "@/components/ui/label"
```

```tsx title="Anatomy"
<Label />
```

Clicking a label focuses or toggles its control. Link the two with `htmlFor` and the control's `id`, or place the control inside the label.

Use [Field](/docs/components/field) when the control also needs a description or an error message.
