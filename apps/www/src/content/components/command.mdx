## Usage

```tsx title="Imports"
import {
	Command,
	CommandCollection,
	CommandDialog,
	CommandEmpty,
	CommandFooter,
	CommandGroup,
	CommandGroupLabel,
	CommandInput,
	CommandItem,
	CommandList,
	CommandSeparator,
	CommandShortcut,
} from "@/components/ui/command"
```

```tsx title="Anatomy"
<CommandDialog>
	<Command>
		<CommandInput />
		<CommandEmpty />
		<CommandList>
			<CommandGroup>
				<CommandGroupLabel />
				<CommandCollection />
			</CommandGroup>
			<CommandSeparator />
			<CommandItem>
				<CommandShortcut />
			</CommandItem>
		</CommandList>
		<CommandFooter />
	</Command>
</CommandDialog>
```

`Command` is an [Autocomplete](/docs/components/autocomplete) whose list is always open, so it takes the same props, like `items` and `filter`.

`CommandInput` has no styles. Set it as the `render` of `InputGroupInput` to style it as an [Input Group](/docs/components/input-group), and give it an `aria-label`.

To keep items clear of the scrollbar, set `scrollbarGutter` on `CommandList`.

To run a command, set `onClick` on `CommandItem`. It also runs when the item is chosen with the keyboard.
