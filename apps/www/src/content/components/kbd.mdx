## Usage

```tsx title="Imports"
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```tsx title="Anatomy"
<KbdGroup>
	<Kbd />
</KbdGroup>
```

## Tips

<Tips>

<Tip title="Label icon keys">

Add visually hidden text inside `Kbd` when the key is an icon.

```tsx {3}
<Kbd>
	<CornerDownLeftIcon />
	<span className="sr-only">Enter</span>
</Kbd>
```

</Tip>

</Tips>

## API Reference

Kbd is built by 9ui, so this is its full API. `Kbd` and `KbdGroup` take the props of a `kbd` element and add none of their own.
