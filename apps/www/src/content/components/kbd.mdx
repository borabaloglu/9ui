## Usage

```tsx title="Imports"
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```tsx title="Anatomy"
<KbdGroup>
	<Kbd />
</KbdGroup>
```

Screen readers read the text inside `Kbd`. Add visually hidden text when the key is an icon.
