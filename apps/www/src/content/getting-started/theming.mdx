title: Theming

9ui is themed with CSS variables in your global CSS file. `:root` holds the light values and `.dark` holds the dark ones. To set up dark mode, see [Dark Mode](/docs/getting-started/dark-mode).

For the full list of default values, see [Installation](/docs/getting-started/installation).

## Change a Color

To change a color, set its variable in `:root` and in `.dark`.

```css title="globals.css"
:root {
	--primary: oklch(54.6% 0.245 262.881);
	--primary-foreground: oklch(98.5% 0 0);
}

.dark {
	--primary: oklch(70.7% 0.165 254.624);
	--primary-foreground: oklch(20.5% 0 0);
}
```

Values are in OKLCH. Any CSS color works.

## Colors

Colors with a `-foreground` pair use it for the text and icons on top.

### Surfaces

| Token | Used for |
| --- | --- |
| `background` / `foreground` | The page and its text |
| `card` / `card-foreground` | Cards and other raised surfaces |
| `popover` / `popover-foreground` | Popups, such as popovers, menus and dialogs |

### Fills

| Token | Used for |
| --- | --- |
| `primary` / `primary-foreground` | Primary actions and selected states |
| `secondary` / `secondary-foreground` | Secondary buttons and badges |
| `muted` / `muted-foreground` | Neutral fills, such as tracks and skeletons. `muted-foreground` is the color of secondary text |
| `accent` / `accent-foreground` | Hovered and highlighted items |
| `destructive` | Destructive actions and errors |

### Status

| Token | Used for |
| --- | --- |
| `warning` | Warnings |
| `info` | Neutral notices |
| `success` | Success states |

Each status color is one token for text and icons. For a background or border, use it at low opacity, like `bg-success/10`. Errors use `destructive`.

### Borders, Inputs and Focus

| Token | Used for |
| --- | --- |
| `border` | Borders |
| `input` | The background of form controls. If it is transparent, read-only fields look the same as editable ones |
| `ring` | The focus ring |

### Charts

| Token | Used for |
| --- | --- |
| `chart-1` to `chart-5` | Chart series |

## Dark Themes

In `.dark`, also set `secondary-elevated`, `muted-elevated` and `accent-elevated`, so fills stay visible on cards and popups. Use the base color with 5 more points of lightness.

```css title="globals.css" {3,5,7}
.dark {
	--secondary: oklch(0.269 0 0);
	--secondary-elevated: oklch(0.319 0 0);
	--muted: oklch(0.269 0 0);
	--muted-elevated: oklch(0.319 0 0);
	--accent: oklch(0.371 0 0);
	--accent-elevated: oklch(0.421 0 0);
}
```

## Radius

To change the corner radius of every component, set `--radius`.

```css title="globals.css"
:root {
	--radius: 0.5rem;
}
```

## Fonts

To change the fonts, set `--font-sans` and `--font-mono`.

```css title="globals.css"
@theme inline {
	--font-sans: "Geist", ui-sans-serif, system-ui, sans-serif;
	--font-mono: "Geist Mono", ui-monospace, monospace;
}
```

## Add a Color

<Steps>

<Step>Add the variables to your CSS.</Step>

```css title="globals.css"
:root {
	--brand: oklch(62.7% 0.265 303.9);
	--brand-foreground: oklch(97.7% 0.014 308.299);
}

.dark {
	--brand: oklch(71.4% 0.203 305.504);
	--brand-foreground: oklch(20.5% 0 0);
}

@theme inline {
	--color-brand: var(--brand);
	--color-brand-foreground: var(--brand-foreground);
}
```

<Step>Use the color in your components.</Step>

```tsx title="component.tsx"
<div className="bg-brand text-brand-foreground">Brand colored content</div>
```

</Steps>
