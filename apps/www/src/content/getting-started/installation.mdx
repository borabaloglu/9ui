## Step by Step

To set up 9ui yourself, use the shadcn CLI or add the files by hand.

<InstallationTabs>

<div>

<Steps>

<Step>Create a project.</Step>

If you already have a project with Tailwind CSS and the `@/*` import alias, skip this step.

```bash title="Terminal"
npx create-next-app@latest
```

For another framework, create the project with its own tool, then add [Tailwind CSS](https://tailwindcss.com/docs/installation/framework-guides) and the `@/*` import alias.

<Step>Initialize 9ui in your project.</Step>

```bash title="Terminal"
npx shadcn@latest init https://9ui.dev/r/init.json
```

This installs the dependencies, adds the `cn` helper, writes the theme to your global CSS file and creates `components.json`.

<Step>Add the 9ui registry to your `components.json`.</Step>

Replace the empty `registries` entry that `init` created.

```json title="components.json"
"registries": {
	"@9ui": "https://9ui.dev/r/{name}.json"
}
```

<Step>Add a component.</Step>

```bash title="Terminal"
npx shadcn@latest add @9ui/button
```

</Steps>


<Step>Set up utility functions.</Step>

```ts title="src/lib/utils.ts"
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
	return twMerge(clsx(inputs))
}
```

## Fonts

The theme uses Inter and Geist Mono. Load them in your app, or change `--font-sans` and `--font-mono`. See [Theming](/docs/getting-started/theming#fonts).

## Icon Libraries

Components use [lucide-react](https://lucide.dev). To use another library, replace the icon imports.

## MCP Server

To let your AI assistant browse and install 9ui components, set up the shadcn MCP server.

```bash title="Terminal"
npx shadcn@latest mcp init
```
