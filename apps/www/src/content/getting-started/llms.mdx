Every docs page is also available as Markdown, so an AI assistant can read it.

## Index

[llms.txt](/llms.txt) lists every page with a one-line description and a link to its Markdown version. Give this file to an assistant that can open links.

## One page

To get a page as Markdown, add `.md` to its URL.

```txt
https://www.9ui.dev/docs/components/popover.md
```

Each page also has a **Copy Markdown** button and an **Open** menu at the top.

## MCP

To let an assistant browse and install components, set up the shadcn MCP server. See [Installation](/docs/getting-started/installation).
