9ui is a set of React components built with [Base UI](https://base-ui.com) and [Tailwind CSS](https://tailwindcss.com). You add them with the shadcn CLI or copy the code. They aren't an npm package, so every component is yours to change.

To get started, see [Installation](/docs/getting-started/installation).

## What You Get

- Over 60 components, each with examples, tips and an API reference.
- Light and dark themes built on CSS variables. See [Theming](/docs/getting-started/theming).
- Right-to-left support in every component. See [RTL](/docs/getting-started/rtl).
- Form guides for [Base UI Form](/docs/forms/base-ui), [React Hook Form](/docs/forms/react-hook-form) and [TanStack Form](/docs/forms/tanstack-form).
- [Skills](/docs/getting-started/skills) and [LLM-ready docs](/docs/getting-started/llms) for AI agents.

## Why Base UI?

[Base UI](https://base-ui.com) components are unstyled and accessible. They handle behavior, focus and keyboard support, and Tailwind CSS handles every style, so there is no default design to override.

## Why Is It Called 9ui?

The number 9 looks like the letter g. Read that way, 9ui becomes "gui", short for graphical user interface.

## FAQ

**Is it free and open source?**

Yes. 9ui is MIT licensed.

**Which frameworks does it support?**

Any framework that runs React, such as Next.js, Vite, Remix and Astro.

**Can I use it without Tailwind CSS?**

No. The components are styled with Tailwind CSS 4.
